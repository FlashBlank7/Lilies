# 经验工作流：帮助新手从数据开始

2026-09-25。

员工可以在项目对话中说「拿到这份数据，不知道怎么分析」，智能体根据项目内已有工作流和使用说明选择能力。每条工作流决定自己的处理范围；明确要求训练时可以直接调用训练流程，不必先完成数据摸底或审批计划。

## 使用

项目空间 → 官方机器学习流程 → **数据摸底与分析建议** → 加入项目，得到可编辑副本及项目 Skill。也可在项目列表的「从示例创建」选择 **数据入门：从看懂资料到选择方法**，获得合成资料、字段说明及四条可独立调用的流程。

1. 选择项目内 CSV、TSV 或 XLSX，填写问题和已有业务信息。多工作表 Excel 需指定工作表名称。首版支持 10 MB、10 万行以内资料；Excel 读取保存的单元格值，不执行公式。
2. 流程先计算字段类型、缺失、重复、不同值数量及数值统计，保存完整字段检查表和重复记录；不会删除或更改原始资料。
3. 原始 LLM 根据有限统计和样例解释问题。影响当前结论的信息缺失时，对话结果卡及运行详情会显示问题表单，可以补充，也可以选择「暂不清楚，先给已有分析」。
4. 点击「提交并继续这次运行」，从原步骤继续；刷新后仍能查看待回答的问题。过期卡片、错误类型或停止后的提交不会启动新任务。
5. 下载 Markdown 分析报告、完整分析 JSON、字段统计 CSV 及重复记录 CSV。报告区分代码事实、分析解释和待确认项；相关性不能证明因果。
6. 下一步建议只准备消息并保留原草稿，不自动发送或运行。员工提出新任务后，智能体再调用合适流程。已有明确目标时，也可以直接要求训练或预测。

## 沉淀的方法

质量建模经验用于解释标签分布、稀有类别、重复实体与批次隔离、预测时点及未来字段；比较简单基线与少量候选，预处理在训练折内拟合，阈值选择与独立测试分开。领域专用标签和工艺阈值不作为通用默认值。

模型结合规则的经验用于区分模型概率、规则拦截、最终决定与人工复核。新数据预测使用固定模型和预处理；只修改规则时调用规则重算流程，不重新训练。流程不能用规则或启发式结果冒充缺失模型的预测。

示例项目提供数据摸底、质量分类训练、已有模型预测与复核、只改规则重算。训练按 `batch` 分组并排除该标识特征；预测需要把模型绑定到 `example-model`，采纳阈值由验证结果或明确业务参数提供。

表格预测不要求提供只用于训练划分的批次列；提供该列时也不会作为模型特征。模型实际使用的特征、指定样本标识仍须齐全。时序场景的样本标识与预测时点要求保持不变，旧模型继续使用原计算环境。

## 接口与兼容

- `human_input` 保留静态标题、说明和字段，新增可引用上游值的 `context`；实际问题随运行状态持久化。
- 项目任务详情的 `runs[].waiting_input` 返回实际 `node_id`、标题、说明、上下文和字段。旧静态表单仍可读取。
- 既有步骤输入接口增加可选 `node_id` 与 `resume`。新页面提交当前节点及 `resume=true`，保存答案并继续原任务；旧客户端不传时仍可先保存再继续。
- `workflow_run(action="respond", task_id, run_id, node_id, inputs)` 使用同一接口逻辑，只提交员工明确提供的回答。查看任务可以取得等待表单；不能为员工猜测业务事实。
- 新流程一遍解释通常调用一次原始 LLM，有补充时再解释一次。统计由代码完成，模型只看到有限字段摘要及少量样例；完整结果保存在项目内。

## 本轮验证范围

自动测试关闭模型出口，解释与对话使用明确的测试替身。统计、文件读写、工作流暂停与接续、训练与预测执行实际代码。真实模型回答质量与真实员工反馈未作为已验证成果。

公司资料仅在本地私有目录验证，不随示例或公开源码分发。已有项目副本不被目录更新覆盖。

- 独立模拟员工账号完成对话发现、读取 Skill、查看工作流及实际调用；刷新后回答「暂不清楚」继续同一任务。另一次在模拟手机中补充业务含义后完成，桌面 CSV 与手机 Markdown 下载事件已确认。
- 信息充分时直接输出报告；另一个对话明确要求训练，经本地对话替身直接调用分类训练并完成实际计算，没有调用分析流程作为前置步骤。
- 建议操作保留未发送的消息草稿；接续完成后结果卡和侧栏更新，普通问题输入不再显示文件选择器。
- 试用项目未经分析流程直接训练，绑定后完成 20 条新数据预测，再仅以规则重算改为全部复核。换文件及排除一个特征后再次训练成功，旧任务输出保留。数据均为合成样例，演示阈值不代表产品放行标准。
- 私有质量案例的已清洗表格完成实际统计，原训练流程复测成功；私有五模型规则案例复测与原结果一致。原始资料、模型、路径和逐项结果留在私有验证目录。这些复测不代表真实 LLM 解释质量或生产准确率。
- 新增分组预测回归检查：新数据有／无批次列得到一致结果和模型版本，缺少真实特征仍失败；原模型、预处理及训练报告保持不变。
