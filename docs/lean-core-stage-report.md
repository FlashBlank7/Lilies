## 第一部分 · 大刀阔斧：砍掉一个实验室，留下一个产品

重构前的仓库是研究性脚手架长满的状态：自我评估仪式、形式化实验管线、协作治理机器彼此缠绕，产品脊柱埋在里面。lean-core 的第一阶段是外科手术式的三板斧：

### 第一斧：后端删除 77 个模块（−110,666 行）

一次提交删掉 formal 实验管线、协作开发栈、bridge 桥接层、治理控制台、黑盒验证、资格认证、H 级评估梯队、复杂度路由、自适应监控、token 监控等全部"机器的机器"。API 从 219 条路由收敛到 183 条。

**保住的产品脊柱**：积木注册表、建造者、工作流运行时/存储、模板、调度器、持久任务、RAG、工作簿、记录系统、连接器、沙盒。

### 第二斧：删除 100+ 死机器测试，撕掉 xfail 面具（−95,787 行）

与死模块配套的测试全部清除。最重要的一刀是**删掉 xfail 清单**——它把 85 个已知失败伪装成"归档的预期冲突"，让测试套件常年虚假全绿。撕掉之后真实失败重新可见，这是后来"443 全绿"含金量的前提。误砍的 scenarios 产品目录在同一提交里甄别恢复。

### 第三斧：scripts 从 196 个文件砍到 13 个（−84,103 行）

证据记录器、阶段报告审计器、实验运行器、进化钩子全部清除。测试套件耗时从 240 秒降到 98 秒。

**砍完的地基**：一个能被完整理解、完整回归、快速迭代的产品内核。此后的一切都长在这个内核上。

## 第二部分 · 至今完成了什么

### 1. 交付主线：从"生成工作流"到"交付一个软件"

回答最初的商业命题——快速交付甲方需求（交付工厂）：

- **会话式交付闭环**：客户说需求 → 莉莉丝搭建 → `ask_owner` 提真问题暂停等回复 → 发布有系统徽章回声 → 交付说明置顶 → 客户随时插话改单。会话页是应用默认落地页；纯工具轮自动合成中文动作行，思考带预览。
- **监理**（可选的第二智能体）：出卷（业主例子→声明式验收规格，1 次模型调用）、监考（零模型成本：发布版跑用例 + 事件账本执行审计 + 终端血缘回溯，能抓"LLM 冒充模型"）、陪看（业主语言解释，机器词硬门 + 经验记忆）。
- **使用者通道**：一条链接 + 一个访问码 = 一个软件。Excel 上传/粘贴/表格编辑进料，成形输出（记录数组→表格），产物下载，运行历史，人工确认续跑。
- **WaaS 界面体系**：每个工作流自动生成**管理 / 极简 / 对话**三件套界面，服务内标签栏切换；标注环节显隐可派生定制界面（一线极简版 / 主管审查版）；隐藏在服务端投影层执行，被隐藏环节的输出零泄漏；莉莉丝可在交付时自己标注（`define_view`）。
- **运行级返修**："不满意？让莉莉丝自己查"按钮——机械证据（节点流水账 + 模板回声疑点 + 运行输入身份）自动附上，返修即重发布。

### 2. 能力主线

- **公式引擎**：手写递归下降解析器（无 eval），`$formula` 中缀表达式 + 聚合/条件/切片，中文报错——终结 LLM 算术幻觉。
- **平台自训模型**：表格模型训练 → 评估 → 晋升治理 → `deployed_model_inference` 积木推理；电梯项目实证 0.883 准确率，units 合同以部署方为权威。
- **画布可用性**：62 个积木出生即合法（默认配置骨架）、Pydantic 错误转中文人话、容器子画布（变更漏斗翻译）、模块循环引用发布时检测。
- **外部系统集成（ERP 级）**：密钥库 + `{"$secret"}` 引用（裸凭证被安全策略拦截且报错指路）、分页拉取、幂等写回、`$sum`/`$count` 带 where 过滤聚合——本阶段末尾以盲测两头验收全绿实证。

### 4. 平台深水修复（静默垃圾 → 诚实失败）

真实项目当"钓竿"钓出的平台缺陷，全部带回归测试修毕：

| 缺陷 | 症状 |
|---|---|
| 密钥通道断头 | 安全策略拦截裸凭证但手册不教、报错死胡同 |
| Loop 嵌套丢运行状态 | 循环体内 `$secret` 以空 owner 被拒 |
| 返修证据无身份 | 账本对不上投诉输入，把正确诊断带进沟里 |
| worker 双执行者连坐 | 认领撞正跑构建时把任务打成 failed，全线崩 |
| 任务预算按生命周期处决 | 跨 7 段返修累计 204>200，第 201 次调用当场处决 |
| `$sum` 双重静默 | where.equals 不解析引用 + 异常吞成 0——四轮返修打不穿的墙 |
| 思考耗尽静默截断 | xhigh 思考烧光输出预算，正文空但节点"成功"（自愈：关思考重试） |
| 模板回声 | 上游空集合、终端输出仍填满——疑点探测 + 诚实空输出纪律 |
| 知识索引跨运行污染 | 固定索引累积旧文档挤占检索（replace 同步模式） |

**"静默垃圾必须变成诚实失败"已成平台第一纪律。**

### 5. 成本工程

单构建曾实测烧掉 **1066 万输入 token（$4.74）**，根因三连：工具结果全文永久滚历史、返修共用一条越滚越长的链、每轮变化的遥测拼进 system 把前缀缓存字节级杀灭（133 次调用 0 命中）。

三刀之后——入史截断（6000 字符 + 可重查提示，transcript 保全文）、老轮次归档（保最近 8 轮）、system 全常量化（遥测挪到末尾消息）——**单次调用全价输入从 15 万降到 1–2 万 token，缓存命中 85–90%，综合成本约为原来的 15%**。

## 第三部分 · 诚实边界与下一步

**产品形态定论**：工作流交付工厂 + 驻场工程师。卖的是"能验收的工作流交付"（按件计价），不是自助 SaaS。驻场工程师的真实工作是修平台，且新领域的缺陷是一次性成本（ERP 领域的 6 个雷已排完）。

**商用前待补**（按阻塞序）：

1. 部署包装：Docker + HTTPS + 数据备份
2. 一客户一实例：把单租户变成卖点（数据物理隔离，SQLite 成为优势）
3. 厂商 ERP 沙箱实战（用友/金蝶等真实协议验证，沉淀连接器配置模板）
4. 报价模型：用 4 个真实项目的模型成本、轮次、工时数据做基准

**明知薄弱、暂不宣传的**：模型供应商单点（DeepSeek）、训练能力仅表格二分类、搜索为新闻源级别、并发未压测。
