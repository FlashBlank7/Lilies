- 已应用：Builder test self-consistency、benchmark node equivalence、terminal-node equivalence、repair confirmation boundary、marketplace Template expandability、timeout/build-deadline evidence boundary、customer-support Template guardrails、Builder teammate deadline/repair-budget governance。

`v0.2.54` 新增的约束是：default path 已经有一条真实闭环证据，但这不是长期监控结论，也不允许删除 fixed-depth override、回退边界和后续 family 监测。
