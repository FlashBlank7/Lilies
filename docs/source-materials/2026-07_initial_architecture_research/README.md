## 使用规则

- 查证历史判断、原始论证和长篇报告时，可以回到本目录。
- 写新的 `current-design` 时，不应直接复制本目录的大段内容；应引用对应 intellectual asset。
- 若发现本目录中仍有长期复用价值的复杂结论，应先提炼成新的 `asset_*.md`，再被后续设计引用。

## 时间优先级

同一主题出现冲突时，优先级为：

1. 2026-07-08 之后的新 stage report、current design 和 intellectual asset。
2. 2026-07-07 的 Word 报告和语言系统。
3. 2026-07-06 的会议回应、概念消歧、语义分析。
4. 2026-07-03 及更早的论文草稿、设计推演和项目说明。

## 内容类型

- 后端核心设计与竞品研究 Word 报告。
