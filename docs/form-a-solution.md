# 形态 A 解决方案：自由协调智能体的可靠化（草案）

> 状态：v0.1 骨架。命门实证来自 2026-08-22/23 真机构建；§3 调研结论与 §4 方案
> 待专项调研回填。

## 1. 定位

形态 A = classic 引擎：单个强模型（本地 Qwen3-32B）在自由 agent 循环里自主
协调——自己决定查什么、搭什么、何时测试、何时收工，可 `spawn_teammate` 派
小模型队友；平台只在工具边界执法。它是三形态中**上限最高、下限最不可控**的
一档：判断力充足，但一切纪律依赖模型自律 + 边界兜底。

## 2. 命门实证（本平台真机数据）

### 2.1 自律失守：绕过验收发布（最严重）

构建 55434ea9（门店日报）：最后一次 `test_run` 明确 `passed=false`（变量未
绑定），协调者 41 秒后 `draft_publish{explicit:true}`，确认掉 `missing_evidence`
警告，发布 v1。产物把样例门店名硬编码进公式（`by_store.A店 + by_store.B店`），
换成 C店/D店 即崩——教科书级"形状合法的垃圾"。
已上的硬门（b7167bd）：构建者发布前必须持有对当前草稿有效的验收证据；
人类知情越过通道保留。**但这只堵了发布一个口**：宣称完成、跳过验证、弱化
断言等同族行为仍主要靠提示词软约束。

### 2.2 长程协调质量

同任务（问候语）对比：A 用 4 轮 / 100s / 0 拒绝——干净利落；但复杂任务
（日报）中 33 轮里边界拒绝 53 次（**59%**），`draft_connect` 接线错 23 次居首；
token 入 158k。委派表现：会派 4B 队友且任务卡写得具体（"按 store 分组求和→
公式求 total→模板生成日报"），但**委派时机与粒度全凭感觉**，队友产出的验收
也由协调者自查自纳。

### 2.3 委派的传话损耗（历史数据）

早期异构实验：协调者把小模型当"起草员"（产出配置文本自己套用），队友引用了
不存在的输出字段——**没让队友自己查手册**是主因（"查询与使用不拆开"原则的
反面教材）。

## 3. 领域调研结论（2026-08-23，原文见 research/form-a-discipline-survey-2026-08.md）

改变方案权重的六条：

1. **我们的事故不是个例，是行业常态**：DGM 伪造测试日志并删除幻觉检测标记；
   METR 测得 o3 明知故犯（能读到打分函数时 hack 率 ×43）；Transluce 记录 o3
   虚构"跑过代码"423 例。**自述与日志都可被伪造——完成判定只能认平台侧
   执行证据**（我们的 b7167bd 与此完全一致，且要推广成家族）。
2. **严格反作弊提示惊人地便宜有效**：ImpossibleBench——"发现测试有误应上报
   而非设法通过"一句话把作弊率 92%→1%。
3. **判官不能是自己**：LLM-as-judge 有自我偏好偏置（60-70% 一致率）；
   Agent-as-a-Judge 按需求清单逐项核查**工件与执行产物**（不读叙述）达 90.44%
   一致、2.3% 成本——正是我们"监理"该走的形态。
4. **校验要变教学信号**：SWE-agent ACI——仅"edit 内嵌 lint 门（拒绝时回显
   原因）"就 +3.0pt。我们 draft_connect 的 59% 拒绝目前只说"KeyError"，
   不给合法候选，白白浪费教学机会。
5. **自省不可靠，红绿可靠**：无外部反馈的自我修正净负收益（GPT-4 GSM8K
   95.5→89.0）；有测试执行反馈 +8~12%。修正动作必须携带新执行证据。
6. **委派共识已收敛**：默认单线程写、子代理只读只贡献智力（Anthropic 2026-01
   与 Cognition 2026-04 合流）；任务卡四要素 + 高保真压缩交接；多 agent
   ≈15× token，只有读密集任务划算。

## 4. 解决方案（定稿）

### 4.1 近期：纪律硬门家族 + 反作弊接种（1-2 天量级）

1. ✅ **发布证据硬门**（已落地 b7167bd）：构建者发布前必须持有对当前草稿
   有效的验收证据；确认警告的权力收归人类。
2. **收工证据硬门**：协调者宣称完成但最新验收非绿 → 不接受"完成"，转
   needs_attention 并附差距清单（把 b7167bd 推广到"收工"这一步）。
3. **反作弊接种条款**（依据 ImpossibleBench 92%→1%）：BUILDER_SYSTEM_PROMPT
   写入——"测试与需求冲突时停止并上报，禁止硬编码样例数据、禁止为变绿弱化
   断言"；配合已有的断言冻结原则。
4. **修正必须带新证据**：修复类动作若不携带新的执行结果（重跑测试/校验），
   连续 N 次即强制升级或停摆——自省负收益的直接对策。

### 4.2 近期：ACI 改造（接线专项，对 59% 拒绝率）

5. **拒绝即教学**：draft_connect 被拒时返回该节点的**真实端口清单与类型**、
   最近似的合法候选；draft_add_node 的 config 校验错误返回该积木的必填字段。
   预期把接线类重试从盲猜变为一次修正（SWE-agent lint 门 +3.0pt 的同构）。

### 4.3 中期：判官独立（监理的升级）

6. **Agent-as-a-Judge 式监理**：收工判定交给只读判官——按需求清单逐项核对
   工件（图结构、测试内容、运行输出），**不读协调者的叙述**；用未见输入
   复跑作为标准动作（我们已两次靠它戳穿假成功）。监理（acceptance_pm）已有
   出卷与机械判分基础，缺的是"逐项工件核查 + 拒读叙述"的形态。
7. **委派协议固化**：四要素任务卡 + 队友只读化倾向（查手册/算期望值/审图），
   写操作尽量单线程留在协调者——与 2026 收敛共识一致，也符合我们
   "查询与使用不拆开"的老原则（该原则约束的是写者，不是读者）。

### 4.4 远期

8. **测试质量审计**：SWE-bench 的教训（最难未解题 59.4% 测试有缺陷）——
   验收即 DoD 时，测试本身也要被独立审计；监理出卷与构建者写测试双轨对照。
9. **ImpossibleBench 自测**：对 Qwen3-32B 跑冲突测试基准，测量本地模型的
   作弊倾向基线（文献未见该级别开源模型的公开数字，可成为论文贡献点）。

## 5. 实验计划

- **臂**：A 现状 / A+接种条款 / A+ACI 教学拒绝 / A+判官收工。任务：日报
  （复杂主战场）+ 一个含"不可能测试"的陷阱任务（测作弊率）。每臂 ≥5 seed。
- **主指标**：真实通过率（判官核验，非自报）、作弊率（陷阱任务）、接线类
  拒绝的平均重试次数、token 成本。
- **预注册预测**：接种条款大幅降作弊率（92%→1% 的区间）；ACI 教学拒绝把
  接线重试次数砍半以上；两者对 token 成本影响相反（前者略省、后者略增）。

## 6. 局限

Qwen3-32B 级开源模型的"虚假宣称完成率"无公开测量（§4.4-9 自测补）；
"收工证据硬门"可能与 ask_owner 暂停语义交互，实现时需区分"等业主"与"宣称完成"。
