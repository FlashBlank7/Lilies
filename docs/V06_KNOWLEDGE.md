# v0.6 项目知识库与语义检索

当前实现项目资料解析、切分、独立 Embedding 连接、索引版本、语义检索及原文出处展示。页面、项目智能体的 `project_knowledge` 工具和 `knowledge_search` 积木共用同一实现。现已提供普通积木组成的引用问答工作流、回答和出处展示及下载。9 月 21 日已补一条完整公开 PDF 的真实引用回答和下载验证；更多问题及智能体自主复用仍待验收，不能把模型替身的回答当作真实 RAG 效果。

## 页面使用

1. 登录后进入项目的“资料与知识”，填写知识库名称、稳定引用名称、片段长度和重叠长度，保存配置。
2. 可以立即创建检索工作流。即使没有模型、资料或索引，也可以保存并编辑；运行时明确指出缺少可用索引，不自动更换模型。
3. 项目负责人配置独立的 OpenAI 兼容 Embedding 连接。API 地址以 `/v1` 等接口前缀结尾，平台调用其 `/embeddings`。此连接只做向量化，不能当作对话模型；密钥仅保存在后端连接目录，普通成员看不到明文。
4. 选择已有项目文件，或粘贴正文。支持可提取文字的 PDF、DOCX 和 UTF-8 文本。扫描 PDF 需要先提供 OCR 文本；当前不解析图片内语义。资料保存页码、段落或行起点、字符偏移及内容哈希。
5. 建立语义索引，输入问题、返回条数和最低相似度进行试用。模型需要的文档/查询前缀可分别填写。运行结果直接展示原文和出处，并可下载包含索引版本的 JSON。
6. 工作流使用知识库下拉选择器；检索返回 `results`、`context`、`version` 和 `retrieved_count`。点击“创建引用问答工作流”得到可编辑的普通积木：输入 → 检索 → 有无资料条件 → 文本模板 → 原始 LLM → 回答和出处。没有资料时走另一条结束分支，不调用 LLM。
7. 在项目设置配置主模型，供回答节点使用；Embedding 连接独立。流程可在主模型未配置时保存，执行到回答节点时才检查模型。模型调用失败保留具体错误，不自动换供应商或增加审查调用。模板、上游字段、系统提示词和模型可通过画布表单修改。
8. 回答和编号对应的原文同时展示，可下载含问题、回答、原文及索引版本的 Markdown/JSON。页面提示不存在的引用编号或未标注引用的回答，保留模型原文；编号能对应并不证明结论受到原文支持，不做额外模型审查或自动重写。
9. 项目 Skill“项目知识与引用问答”介绍知识库查询和已有工作流的发现、输入输出检查及调用方式。列表只返回名称与用途，正文按需读取，用户可以编辑。

项目智能体的 `project_knowledge` 工具可以直接新建/配置知识库（configure）、添加或移除资料（add/remove）、建立索引（build），不要求先有工作流。它与页面操作同一份资料和修订号；过期修改返回冲突，失败或取消构建保留旧索引，未变化的就绪索引不重复向量化。模型连接仍由负责人单独配置，工具不会替换连接。查看 PDF、DOCX 等原资料时提供原文件下载；当前阅读面板只预览文本、表格和 HTML，不把二进制文件解码成文本。

每个知识库最多 100 份资料、1000 个片段，单份文件最多 20 MB、正文最多 100 万字符，PDF 最多 500 页。当前采用按原文字符窗口切分及向量余弦相似度，未引入重排器或大规模向量数据库。切分不会调用大模型。

## 索引、权限和失败处理

资料或切分配置变化后显示待建立索引；模型地址、名称或协议变化后拒绝混用旧向量。一次建立索引期间资料被编辑时，提交返回冲突，旧索引保留。失败不会覆盖已有版本，已就绪版本再次点击建立索引不会重复向量化。

每次工作流运行固定知识索引版本；后续新运行读取新版本，已保存结果不随资料修改而变化。继续旧运行仍需原 Embedding 连接可用。版本记录的是配置的模型标识和地址，服务商在同名模型下原地替换权重不在当前可检测范围内。

项目成员权限同时覆盖知识库、资料操作、检索与连接接口。协作者可以使用和编辑共享知识，但仅负责人或管理员可以修改模型连接。跨项目读取、移除成员后的读取和检索均拒绝。索引建立当前是页面发起的同步操作，展示执行中状态；尚未提供独立的索引任务停止/恢复页面。

远程出口默认为关闭。关闭时不会把正文或查询发送到远程 Embedding 服务；显式配置的本机回环接口可用于本地模型。没有自动选择服务商、模型或开启远程访问。
