# 按物料与需求生成下料候选

2026-09-25。员工拿到可用物料与定长或长度范围需求时，先生成每根物料能够产出的数量组合，理解长度、损耗和需求上限的影响。流程进入公共工作流市场；同名自编示例包含本流程、已有候选比较和共同需求分配流程，创建后均可编辑。

## 操作与产物

1. 上传物料CSV/Excel（`stock_id,material,length`）和需求表（`demand_id,material,length,quantity`）。选择“长度范围”时，需求以`min_length,max_length`替代`length`；相同上下限表示固定尺寸。每行物料是一根；需求数量为剩余数量。标识不能重复，类型必须明确，相同类型才参与组合。字段不同可用已有表格整理流程先映射。
2. 选择文件、Excel工作表和共同长度单位，填写实际单次切缝及每根两端合计预留。两表可选`unit`列若存在，必须与表单相同，不自动推测或换算单位。
3. 选择最大段数、需求种类和计算上限。运行得到候选、每个候选的需求数量、各根无方案原因、输入快照和中文说明。长度计算采用精确十进制，不将略微超长的组合四舍五入成可行。
4. 明确比较目标后，用`comparison_inputs`调用项目内的[候选方案约束检查与比较](CANDIDATE_COMPARISON_WORKFLOW.md)，或者手动选择刚生成的`candidates.csv`、按`stock_id`分组。默认不填业务优先级或权重。没有候选时先查看原因。

只改变比较偏好可以复用已有候选；换需求或损耗新开运行，旧输入和结果保留。没有自动训练、调用模型、消耗库存或生产回写。

## 长度范围与分配方式

范围需求默认按上下限的相同比例扩展；也可以先分配中点，剩余量按需求表行顺序增加。在不足以分配中点时，两种方式均按区间比例。同一需求在一个候选中各段等长；中点优先方式会受需求行顺序影响。

实际长度按明确的小数位向下取整，余量保留。下限先向上、上限向下收紧到该精度，无可表示尺寸则报错。默认6位是计算配置，不代表设备能力。每个数量组合只输出所选方法的一种长度分配，不枚举连续区间里的所有尺寸，也不证明长度分配全局最优；离散尺寸需另行处理。

自编`需求-范围.csv`和范围练习已随示例提供：100 mm物料切两段、每段计1 mm切缝，需求范围30–45及40–55。比例方式得44/54，中点优先得45/53；改变表顺序得43/55。可以换分配方式直接重跑并核对`patterns.csv`，旧结果保留。

## 损耗口径必须明确

| 配置 | 长度使用量 | 适用前提 |
|---|---|---|
| 每段各计一道切缝 | 产品长度和＋段数×单次切缝 | 每段从原料分离，末段也计一道 |
| 仅相邻段间计切缝 | 产品长度和＋（段数−1）×单次切缝 | 末段不需要再与剩余料分离；有余量时需确认实际工艺 |

总端部预留从物料长度扣一次。报告分开显示产品长度、锯缝损耗和剩余长度，剩余料能否再用并未知，不直接称为废料。填写0必须是任务明确给出的损耗，不是平台替客户判定“没有损耗”。

## 经验来源与限制

原一维切割工程先枚举一类、两类和三类需求的段数组合，核对长度，再处理余料、设备和配对，最后评分。此流程提取数量组合和长度可行性，定长与区间尺寸分别看待；客户设备尺寸、危险区段、配棒规则、评分系数和超需求余量没有变成通用默认。

成功枚举只覆盖所声明的需求、段数及种类范围；不枚举同一组合的排列，也不决定实际切割顺序。每根物料独立受同一份需求数量限制，**不能把各根首选直接拼成整体排程**：总需求、共享库存、设备与时间仍需后续分配检查。既有比较流程只比较输入候选，同样不证明全局最优。

每次最多30根物料、12种需求、每根12段及6类需求；默认6段、3类、2万搜索分支。分支上限可在100至20万间设置，候选最多1万。达到上限会明确失败，保留本次输入但不发布截断候选表；减少本次范围或调整参数后可重新运行。CSV/TSV/XLSX文件限10MB，多工作表要明确选择。资料缺字段、单位不一致、类型不明和重复标识均指出具体位置。

## 验证记录

- 方法测试将两种切缝模式、两种段数上限和三种类型上限，与独立笛卡尔积枚举逐项比较；覆盖十进制边界、需求上限、无方案、同名新内容、快照保持和计算上限失败修复。
- 从原工程提取三个未修改的纯长度分配函数在禁网Docker执行；三组构造定长输入产生26个组合。平台执行得到相同组合，产品长度、切缝损耗和余量共78项数值一致。仅验证定长子情形，不等同原设备、配棒、可变长度分配或真实排产验收。
- 模拟智能体通过现有工具发现比较流程、查看输入，并将生成结果交给该流程实际运行；不调用真实大模型推理。新流程16项和受影响后端回归合计65项通过，10项需额外计算配置跳过。
- 客户源码及详细对照留在本地私有目录。公共示例尺寸、类型和需求全部自编；没有生产效果承诺。页面验证结果记录在本周开发记录。
