## 数据与使用边界

使用 [UCI Wine Quality](https://archive.ics.uci.edu/dataset/186/wine+quality) 的红葡萄酒数据（Cortez 等，2009，DOI 10.24432/C56S3T，CC BY 4.0）。原 CSV 有 1599 行、11 个输入特征和质量评分。原文件 SHA256 为 `4a402cf041b025d4566d954c3b9ba8635a3a8a01e039005d97d6a710278cf05e`。

以 11 个特征组成的文本哈希分组切分，1260 行用于训练，339 行作为新数据；相同特征的样本不会跨越这两组。上传的新数据不含评分，保留标签没有用于本次训练、调参或效果评价。训练组内部仍有重复行，当前交叉验证未按重复组切分，指标可能偏乐观。此次验证平台功能，不代表工业模型效果或客户业务已验收。

原生文件选择自动化仍返回 `Not allowed`。实际导入通过页面“粘贴表格数据”及 multipart 上传完成，不把它称为原生文件选择器通过。

## 暴露的问题与修复范围

第一次长训练停止后，后台等待逻辑把中断当成“新结果”，再次唤醒智能体；智能体随即恢复了任务。该次任务最终成功不代表停止语义通过。修复后仅成功或失败的任务触发结果处理，中断任务等待用户继续。回归验证中断不会增加模型轮次，人工继续沿用原任务。另从页面启动真实 CPU 训练，停止后保持中断约 30 秒，手动点击继续后完成同一任务。

真实智能体重复停止用例时，已授权服务商返回 HTTP 402，未成功执行工具；因此修复后的真实智能体完整停止复测仍未通过。没有切换服务商或扩大预算，主服务已恢复关闭远程模型出口。人工训练及已绑定模型预测仍可使用。

另外两个实际问题已修复：项目连接原先没有统一遵守服务器的 `MODEL_EGRESS_ENABLED`；现主模型、视觉模型和生成模型都使用该设置，测试以替身 HTTP 验证关闭时无远程请求。智能体调用 `project_action(wait, task_id)` 原先错误要求关联业务事项；现可直接等待原任务，返回成功、失败或中断状态，不恢复任务、不创建事项，跨项目任务仍拒绝。

## 模型调用实测

取自同一会话的实际用量事件。耗时为开始处理请求到结束处理的近似墙钟时间，包含工具和等待时间；缓存读取单列，不等同于新增输入。服务商没有提供可用费用数据，不能把记录中的零值解释为免费。

| 请求 | 模型调用 | 输入 token | 输出 token | 缓存读取 token | 耗时 |
| --- | ---: | ---: | ---: | ---: | ---: |
| 分析并独立训练 | 11 | 26226 | 4159 | 215296 | 约 28.5 秒 |
| 发现流程、复用及报告 | 8 | 12211 | 9285 | 339328 | 约 45.7 秒 |
| 长训练与第一次停止诊断 | 9 | 39766 | 5154 | 635136 | 约 98.9 秒 |

第三项包含修复前不应出现的自动继续。首次训练中有两次工具错误：使用了错误的数据列表工具，以及上述等待任务的旧事项限制。复用时有两次工具错误：复用了不同请求的幂等标识，以及用项目文件工具读取模型产物目录；后续改用正确入口完成。保留这些成本，不以最终成功掩盖中间错误。此次没有同条件修复前后完整对照，不宣称整体提速比例。
