# 已有结果整理为汇报幻灯片

把已完成的数据分析、研究笔记或模型评价整理成内部汇报。员工可以通过对话提出要求，也可以从示例或公共工作流目录加入可编辑副本。改汇报不重新训练，制作汇报不要求先有模型。

## 员工怎么使用

1. 从「从示例创建」选择「已有结果整理为汇报幻灯片」，得到两份自编稿件、一条流程和使用说明。
2. 在运行表单选择Markdown／TXT稿件，或直接填写内容；两项只填一项。标题与副标题可选。
3. 查看逐页图片，下载可编辑PPTX、PDF、原稿和内容出处。文字和表格是原生对象，图片保持比例。
4. 更换为 `修改后的汇报.md` 再运行，比较内容与页数；历史文件保持原状。

可以对智能体说：“把项目里的分析结果整理为面向新员工的汇报，保留数据出处、样本量和不能确认的事项。”项目自带「报告与演示文稿」Skill，按需读取正文及 `render.py`。已有流程可以发现和调用；一次性需求也可以通过项目代码执行同一生成器，无需先创建流程。对话整理稿件使用项目获准的模型，排版生成器本身不调用模型。

## 支持内容和边界

- Markdown标题、段落、列表和表格自动分页；宽表分组展示并重复第一列。单元格或标题过长时给出行号，可拆分后重跑。
- PNG／JPEG使用独立一行 `![说明](项目内路径)`；文件稿件中的图片也可相对所在目录引用。不能引用外网或项目外图片。
- 保存本次原稿、图片副本和内容哈希。演讲者备注记录原稿路径、哈希、原文行号及拆表列号；正文引用保留为可见文字。
- 首版为简洁内部汇报排版，最多60页。不复刻任意客户模板、复杂公式或动画。Markdown格式符会转换，业务文字、数字及单位不由生成器改写。
- 原分析的缺项和限制应保留。示例指标明确标为自编排版数据，不能当作实际训练结果。

## 计算环境

沿用项目Python代码积木和 `project_code` 的Docker环境。PptxGenJS生成原生文字与表格，LibreOffice Impress转换PDF，Poppler生成预览。依赖只在构建时安装，运行仍禁网，没有另建文档服务或运行时。

固定依赖PptxGenJS 4.0.1，锁文件在 `runtime/documents/`。[官方发布记录](https://github.com/gitbrent/PptxGenJS/releases)；原生[表格配置](https://gitbrent.github.io/PptxGenJS/docs/api-tables/)和[备注](https://gitbrent.github.io/PptxGenJS/docs/speaker-notes/)用于内容及来源保留。

已有基础计算镜像后构建，例如：

```sh
docker build -f Dockerfile.documents --build-arg BASE_IMAGE=agent-platform-sandbox:latest -t agent-platform-sandbox:documents .
```

设置 `SANDBOX_IMAGE=agent-platform-sandbox:documents` 并重启后端。缺少Node、PptxGenJS、Impress或预览组件时显示具体原因，保留准备阶段结果以便修复后继续。不要为解决依赖问题开启运行网络。
