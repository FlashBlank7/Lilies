## 6. Experiment Result

Evidence:

- Raw JSON: `docs/experiment-status/evidence/experiment_v0.2.37_e04_local_repair_vs_full_rebuild_2026_07_09.json`
- DOCX: `docs/experiment-status/reports/2026-07-09_2021_E04_local_repair_vs_full_rebuild.docx`

| Metric | Local repair | Full rebuild |
| --- | --- | --- |
| Success | `true` | `true` |
| Elapsed seconds | `0.0153` | `57.127` |
| Operations / calls | `1` draft op | `15` model calls, `22` tool calls |
| Build/test status | test passed | build `published`, test passed |
| Draft node types | `start`, `template_transform`, `end` | `start`, `template_transform`, `answer` |

Conclusion:

- Local repair was sufficient and much cheaper for this localized template failure.
- Full rebuild also succeeded, so this is not evidence that rebuild is unreliable.
- Engineering policy should prefer local repair when readable test frames and failure targets point to a specific node/config field, and escalate to rebuild for broader architecture or requirement failures.
