# v0.2.24 Platform Harness Stdio Policy Controls

## 1. Stage Goal

Close the next Platform Harness visibility slice by exposing stdio MCP policy controls and blocked reasons through a read-only backend API and Studio monitor panel.

This stage does not implement allowlist-grade stdio MCP firewalling. It makes the current enforcement boundary visible, auditable, and harder to misdescribe.
