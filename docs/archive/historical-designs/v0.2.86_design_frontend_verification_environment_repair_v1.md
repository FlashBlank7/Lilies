## Problem

Frontend verification has repeatedly failed because `node` and `npm` are not on the default PATH, even though a usable Node installation exists under `~/.nvm/versions/node/v24.15.0/bin` and the frontend package files are present.

## Boundary

- Do not install global tooling.
- Add a repo-local verification runner that discovers usable Node/npm candidates and repairs PATH for the verification process.
- Run `npm run lint` and `node_modules/.bin/tsc --noEmit` through the repaired environment.

## Design

- Add a reusable Python helper that probes candidate Node prefixes.
- Prefer existing PATH, then known local user/runtime Node locations.
- Prepend the selected Node bin directory to PATH only for child verification commands.
- Return structured evidence for probe, lint, and tsc checks.

## Acceptance

- Runner discovers a usable Node/npm pair.
- `npm run lint` passes.
- `node_modules/.bin/tsc --noEmit` passes.
- Evidence records selected Node path and command results.
