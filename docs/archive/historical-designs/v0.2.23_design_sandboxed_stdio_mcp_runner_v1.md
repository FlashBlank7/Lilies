## 1. Goal

Add a sandbox-backed stdio MCP runner path that preserves JSON-RPC initialization and tool call exchange.

## 2. Module Boundary

Backend:

- `platform/backend/src/agent_platform/tools/mcp.py`
- `platform/backend/src/agent_platform/tools/core.py`

## 3. Implementation Plan

1. Extend `MCPClient.call_tool()` to accept an optional sandbox.
2. If transport is stdio and a sandbox is supplied, run a Python bridge inside the sandbox.
3. The bridge starts the configured server command, sends initialize, initialized notification, and tools/call JSON-RPC messages, waits for matching response IDs, then terminates the server.
4. `MCPTool.execute()` passes `context.sandbox` to the client.

## 4. Acceptance Criteria

- HTTP MCP behavior is unchanged. Completed.
- Host stdio fallback remains available for full/full policy. Completed.
- Sandboxed stdio path uses `context.sandbox.run()`. Completed.
- The result unwrap behavior stays compatible with existing MCP responses. Completed.
