## Problem

E08 productization can be overstated if one policy-controls surface is described as full sidecar completion. Complexity-router also needed to remain intentionally deferred after E08 selection.

## Boundary

This stage defined language and disposition only. It did not implement complexity-router guardrails.

## Final Design

- Product/API/UI language says workflow-internal passmode is `soft_configurable`.
- Product/API/UI language says Platform Harness policy is a `hard_boundary`.
- `not_full_sidecar_completion=true` is returned by the API and shown in Studio.
- Complexity-router remains deferred until a future stage selects guardrails, overrides, rollout metrics, and default-safety design.

## Acceptance

- API/UI wording avoids false full-sidecar claims.
- Stage report preserves complexity-router guarded rollout.
- Historical record names remaining risk.
