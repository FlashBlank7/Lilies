## Problem

The Try result panel now explains status and recovery, but successful output content is still primarily raw JSON. Non-technical users need a compact preview of key output values before opening the technical payload.

## Boundary

- Frontend-only presentation.
- No mutation endpoint.
- Raw JSON remains visible.
- Preview should be compact and avoid layout overflow.

## Solution

- Add `tryResultOutputPreviewItems` from top-level `run.outputs`.
- Show up to three key/value previews using the existing compact value style.
- Show hidden output count when there are more keys.
- Render with `data-try-result-preview="output"`.

## Acceptance Criteria

- Successful output keys are visible before raw JSON.
- Empty outputs show a readable empty state.
- Long values are shortened.
- Source, i18n, style, and manifest markers are covered by v0.3.35 tests.

## Final State

- Implemented `tryResultOutputPreviewItems` from top-level `run.outputs`.
- Added `valueKind`.
- Added `data-try-result-preview="output"`.
- Shows up to three output entries plus hidden count before raw JSON.
- Verified by `scripts/v03_35_try_result_output_preview.py` and `tests/test_v03_35_try_result_output_preview.py`.
