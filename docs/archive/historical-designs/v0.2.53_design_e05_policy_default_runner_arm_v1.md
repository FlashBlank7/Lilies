# v0.2.53_design_e05_policy_default_runner_arm_v1

## Problem

`v0.2.52` 已经把 omitted `reuse_depth` 产品化为 adaptive 默认策略，但 canonical E05 runner 还不能直接表达这个省略参数路径。

## Boundary

- In scope: 给 canonical E05 runner 增加 `policy_default` arm。
- In scope: 在结果 JSON 和 summary 中记录默认路径元数据。
- Out of scope: 改写 adaptive heuristic 或重做整个 E05 实验框架。

## Final Solution

- 新增 `policy_default` arm，并在 preflight / live runner 中显式省略 `reuse_depth` 查询参数。
- 扩展 `summarize_events()`，记录 `reuse_depth_source`、`defaulted_by_policy`、`default_policy_version` 与 `available_overrides`。
- 在 arm 结果中加入 `policy_default_resolution` 和 `resolved_template_strategy`，让 raw JSON 与 compact summary 都能直接读出默认路径。
- 为 runner 和 summary 补齐确定性测试。

## Acceptance

- canonical runner 可直接运行 `policy_default` arm。
- raw JSON 与 summary 都能看出 `policy_default -> adaptive -> concrete depth`。
- 确定性测试通过。
