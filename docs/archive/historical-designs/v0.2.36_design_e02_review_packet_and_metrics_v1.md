# design_v0.2.36_e02_review_packet_and_metrics_v1

## Goal

Generate comparable raw JSON and readable TestFrame review packets from actual Lilies test execution, then compute deterministic review-effort metrics.

## Module Boundary

In scope:

- New experiment script under `scripts/`.
- Existing `WorkflowRuntime.run_test_suite()` behavior.
- JSON evidence under `docs/experiment-status/evidence/`.

Out of scope:

- Changing `WorkflowRuntime.run_test_suite()` output schema.
- Frontend UI changes.
- Human-subject recruitment.

## Design

Create a bounded experiment script that:

1. Starts an in-process Lilies API app using existing test fixtures.
2. Builds one or more failing test cases through real draft operations.
3. Runs `/api/v1/applications/{id}/tests/run` to obtain the actual test suite report.
4. Creates two review packets from the same report:
   - `raw_legacy_json`: strips `frame`, `readable_report`, `summary.frames`, and `feedback_hints`, leaving only raw assertions/tool evidence style output.
   - `readable_testframe`: keeps `summary.frames`, `frame`, `readable_report`, and `feedback_hints`.
5. Computes deterministic metrics:
   - serialized character count
   - number of JSON paths a reviewer must inspect to answer the task
   - whether category/title/status/failure target/feedback hints are explicit fields
   - answer-key recoverability from each packet

## Acceptance Criteria

- The evidence JSON includes the original actual `run_test_suite()` report.
- Raw and readable packets are both present and derived from the same source report.
- Deterministic metrics are present for each packet.
- The design does not claim real human-review timing without human evidence.
