## 1. Goal

Prevent Builder Team post-template customization from silently drifting into mandatory-test required-node mismatches, and surface graph validation feedback after risky mutations.

## 2. Module Boundary

Primary files:

- `platform/backend/src/agent_platform/builder.py`
- `tests/test_workflow.py`

Read-only dependencies:

- `platform/backend/src/agent_platform/applications.py`
- `platform/backend/src/agent_platform/workflow_models.py`

## 3. Implementation Plan

1. Add a Builder helper that validates whether removing a node would break mandatory test `required_node_types`.
2. Apply the guard to `draft_remove_node`.
3. Return a post-operation validation summary for risky draft mutations: update node, remove node, remove edge, connect edge, and test add.
4. Add deterministic test coverage for rejecting removal of the only node type required by a mandatory test.

## 4. Acceptance Criteria

- Builder refuses to remove the last node of a type required by a mandatory test unless the test is changed first: covered by `test_builder_refuses_to_remove_last_node_required_by_mandatory_test`.
- The failure message tells the Builder Team to update tests or add a replacement node: covered by stream event assertion.
- Risky mutation results include validation feedback: implemented for update/remove/connect/test-add mutation results.
- Focused tests pass: combined focused v0.2.44 tests -> `9 passed, 1 warning`.
