## Problem

Draft patch preview is intentionally non-mutating. Worker offload must preserve that property, because mutation belongs to explicit draft operations and reviewable design changes.

## Boundary

- Worker handler returns operations only.
- Worker handler does not call draft mutation APIs.
- API preview path remains available for direct use.
- Preview parser remains deterministic and model-free.
