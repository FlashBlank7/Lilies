## Problem

The `v0.2.53` omitted-depth live acceptance proved that `policy_default` resolves to adaptive/deep correctly, but the Builder timed out after `draft_inspect`, `catalog_search`, and `template_suggestions`. It never recorded `BuildPlan.reuse_depth`, never expanded the data analyzer template, and never reached mandatory test closure.

The failure was therefore not policy selection correctness. It was an execution reliability gap after the policy-default suggestion result.

## Boundary

- In scope: Builder guidance, template suggestion response metadata, E05 runner instruction, and focused deterministic regression tests.
- In scope: preserving explicit overrides for `none`, `shallow`, `deep`, and `adaptive`.
- Out of scope: changing adaptive heuristics, running E08 sidecar/passmode, or adding long-term monitoring.
- Out of scope: increasing provider timeout as the primary fix.

## Final Design

Policy-default template suggestion payloads now include a compact execution contract:

- `next_step`: `set_build_plan_reuse_depth`
- `reuse_depth_to_record`: the concrete `effective_reuse_depth`
- `then`: the recommended concrete action, such as `compose_modules`
- `preserve_reuse_depth_source`: `policy_default`

Builder tool results expose the same contract at top level. Builder and E05 runner instructions require treating `reuse_depth_source="policy_default"` as a resolved adaptive policy decision: immediately record the concrete `effective_reuse_depth` in `BuildPlan.reuse_depth`, preserve policy-default evidence, and proceed to the returned recommended action before broad search or draft mutation.

## Acceptance

- API/Builder suggestion payloads for omitted depth still report `reuse_depth="adaptive"`, `reuse_depth_source="policy_default"`, and `effective_reuse_depth`.
- Policy-default suggestion payloads include the execution contract with the concrete depth and recommended action.
- The E05 policy-default arm instruction contains an immediate BuildPlan concretization requirement.
- Focused regression tests pass.
- One bounded live `data_analyzer` policy-default acceptance reaches publish closure.
