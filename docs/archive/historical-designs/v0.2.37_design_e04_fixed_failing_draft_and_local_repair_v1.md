# design_v0.2.37_e04_fixed_failing_draft_and_local_repair_v1

## Goal

Create a reproducible failing BlockFlow draft and measure a local repair path using real Lilies draft operations and test execution.

## Module Boundary

In scope:

- New experiment script under `scripts/`.
- In-process Lilies API app.
- Draft mutation and `run_test_suite()` evidence.

Out of scope:

- Changing Builder behavior.
- UI changes.
- Generalizing beyond localized failures.

## Design

The fixture workflow:

- Start accepts `name`.
- Template node returns `Hi {{ name }}`.
- End returns `greeting`.
- Mandatory test expects `Hello Ada`.

Initial test fails because the template is locally wrong. Local repair updates exactly one template node to `Hello {{ name }}` and reruns the same mandatory test.

Metrics:

- operation count
- duration
- before/after test status
- changed node id and field
- draft revisions consumed

## Acceptance Criteria

- The script records the failing pre-repair test report.
- The local repair uses `update_node`, not a hand-edited JSON bypass.
- The post-repair test passes.
- Evidence JSON contains timings and operations.
