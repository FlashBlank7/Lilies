## Problem

After v0.2.130, the remaining E08 sidecar boundary is narrow but still serious. Selecting external KMS provider integration is not the same as implementing provider-backed KMS, and even implementing provider-backed KMS would still require a separate full-sidecar completion audit.

## Boundary Rules

- v0.2.131 may select external KMS provider integration.
- v0.2.131 must not claim external KMS integration is implemented.
- v0.2.131 must not claim full Platform Harness sidecar completion.
- v0.2.131 must keep the next stage's closure target narrow and executable.

## Evidence Contract

The selector must report:

- `external_kms_provider_integration_selected=true`
- `external_kms_provider_integration_implemented=false`
- `e08_full_sidecar_completion_claimed=false`

## Completion Criteria

- Tests assert the not-implemented and not-full-sidecar invariants.
- Stage report lists external KMS implementation as carried forward to v0.2.132.
- Ledger/status text remains explicit that full sidecar completion is still not closed.
