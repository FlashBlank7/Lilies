## Problem

A recommended action can accidentally become a hidden model-team startup shortcut.

## Boundary

- Recommendation button is always `type="button"`.
- It may focus the guarded button but must not click it.
- Existing two-step guard remains authoritative.

## Solution

- Add refs for the requirement textarea and guarded build button.
- `runDetailBuildRecommendedAction` only focuses elements and sets local notice.
- Harness verifies no new build trigger path.

## Acceptance Criteria

- No new form submit or build API path appears.
- Confirm state maps to `guarded_build_button`.
- Live evidence calls only `/health`.

## Final State

- Recommendation button is `type="button"`.
- Confirm and arm states map to `guarded_build_button`.
- Existing two-step build guard remains authoritative.
- Live evidence calls only `GET /health`.
