## 1. Goal

Add a read-only Platform Harness policy controls API that explains current governance settings and stdio MCP policy decisions.

## 2. Module Boundary

Backend:

- `platform/backend/src/agent_platform/platform_harness.py`
- `platform/backend/src/agent_platform/api.py`

## 3. Implementation Plan

1. Add a stdio MCP policy explanation method to `PlatformHarness`.
2. Make `enforce_stdio_mcp_policy()` use that explanation method so enforcement and visibility share one decision source.
3. Add `PlatformHarness.policy_controls()` returning:
   - network egress policy and allowlist
   - secret policy enabled flag
   - worker lease defaults
   - stdio MCP support flags
   - scenario decisions for host full network, sandboxed no-network, sandboxed allowlist, and restricted unsandboxed paths
4. Add `GET /api/v1/platform/harness/policy-controls`.

## 4. Acceptance Criteria

- API returns deterministic JSON without mutating Platform Harness tasks. Completed.
- Stdio allowlist scenario is visible as blocked with an operator action. Completed.
- Sandboxed no-network scenario is visible as allowed. Completed.
- Runtime enforcement still raises `PlatformHarnessViolation` for blocked stdio MCP paths. Completed.
