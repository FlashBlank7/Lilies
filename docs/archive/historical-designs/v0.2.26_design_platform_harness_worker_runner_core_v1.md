## 1. Goal

Add a reusable worker runner primitive that consumes Platform Harness queued tasks through worker leases.

## 2. Module Boundary

Backend:

- `platform/backend/src/agent_platform/worker_runner.py`
- `platform/backend/src/agent_platform/platform_harness.py`

## 3. Implementation Plan

1. Add `PlatformHarnessWorkerRunner`.
2. Accept `PlatformHarness`, `worker_id`, `lease_seconds`, and a handler registry.
3. `run_once()` lists queued tasks, skips unsupported kinds, claims leases for supported kinds, dispatches handlers, and finishes tasks as succeeded or failed.
4. Store worker runner result metadata in task metadata.
5. Return structured run results for observability.
6. Keep this independent from FastAPI request handling.

## 4. Acceptance Criteria

- Runner can complete a queued task through a registered async handler. Completed.
- Runner can fail a queued task when the handler raises. Completed.
- Unsupported tasks remain queued and unclaimed. Completed.
- Lease conflict behavior is delegated to Platform Harness. Completed.
