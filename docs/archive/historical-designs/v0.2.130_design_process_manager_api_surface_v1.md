## Problem

Process lifecycle must be exposed as a product surface. A subprocess class alone is not enough.

## API Surface

- `GET /api/v1/platform/harness/worker-process-manager`
- `POST /api/v1/platform/harness/worker-process-manager/start`
- `POST /api/v1/platform/harness/worker-process-manager/stop`
- `POST /api/v1/platform/harness/worker-process-manager/restart`

## Acceptance

- Snapshot exposes configured command, pid, desired state, observed state, return code, timestamps, and boundary flags.
- Start/stop/restart endpoints are idempotent enough for operator use.
- Empty command returns a clear start-time error rather than inventing a process.
