## Problem

Users can select a customer behavior but cannot explicitly clear the selection before drafting.

## Boundary

- Clearing the selection must not erase the editable requirement text.
- Clearing selection must not call backend endpoints.

## Solution

- Add a clear selected scenario button in the summary.
- Reset `selectedExampleId` only.

## Acceptance Criteria

- Clear action removes selected-state UI.
- Requirement text remains editable and unchanged.
- No backend calls are introduced.
