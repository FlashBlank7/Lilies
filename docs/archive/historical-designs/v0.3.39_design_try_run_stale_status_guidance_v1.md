## Problem

If a queued or running status appears to stay unchanged, non-technical users may not know whether to wait, cancel, or start another run. Since duplicate starts are now blocked, the guard should explain the safe options.

## Boundary

- Guidance only.
- No automatic refresh button.
- No automatic cancel or retry.

## Solution

- Add stale-feeling guidance copy inside the active-run guard.
- Keep explicit cancel as the only stop action.
- Preserve run button disablement while active.

## Acceptance Criteria

- Guidance says wait or cancel explicitly.
- Guidance does not suggest starting another run while active.
- Harness verifies source markers and no new mutation endpoint.
