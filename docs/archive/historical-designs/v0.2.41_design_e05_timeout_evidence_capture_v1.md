## 1. Goal

Enhance E05 experiment evidence so provider timeouts and Platform Harness failure metadata introduced in v0.2.40 are visible in the raw result JSON.

## 2. Module Boundary

Primary files:

- `scripts/e05_template_reuse_depth_experiment.py`
- `tests/test_e05_template_reuse_depth_experiment.py`

Read-only dependencies:

- `platform/backend/src/agent_platform/builder.py`
- `platform/backend/src/agent_platform/runtime.py`
- `platform/backend/src/agent_platform/platform_harness.py`

## 3. Data Flow / Control Flow

Current chain:

1. E05 script runs Builder arms.
2. It collects build, draft, stream events, Builder task, and benchmark report.
3. It summarizes template suggestion/expand events.
4. Provider timeout evidence can remain buried in raw stream events or task metadata.

Target chain:

1. E05 script runs Builder arms.
2. It collects Builder task metadata and build stream events.
3. It extracts:
   - provider failure events;
   - model timeout events;
   - `build.needs_attention` failure metadata;
   - Platform Harness task `metadata.failure`.
4. Each arm result exposes a compact `failure_summary`.

## 4. Implementation Plan

1. Extend `summarize_events()` to return:
   - `provider_failure_events`;
   - `model_timeout_events`;
   - `needs_attention_events`.
2. Add helper `summarize_failure(completed, builder_task, event_summary)`.
3. Include `failure_summary` in every completed arm.
4. Add deterministic test events that include v0.2.40 timeout/failure shapes.
5. Keep existing E05 output fields stable.

## 5. Acceptance Criteria

- Existing E05 tests still pass.
- New test proves timeout/Harness metadata is extracted.
- Result JSON for paid/live run can show whether a failed arm had provider timeout evidence.
