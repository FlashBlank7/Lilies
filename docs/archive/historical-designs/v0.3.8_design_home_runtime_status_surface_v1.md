## Problem

The home page is the first product surface. If it claims the environment is connected while auth or runtime is broken, a non-technical user will not know whether their next action is safe.

## Boundary

Keep the topbar compact. Do not add a diagnostic dashboard to the home page.

## Solution

- Fetch `/api/platform/health` on load.
- Combine health state with application-list auth state.
- Render a topbar runtime badge with `data-runtime-status`.
- Show short state and detail text only.

## Acceptance Criteria

- Home page has `data-runtime-status` marker.
- Connected, auth-required, stale, unavailable, and checking copy exists.
- No builder/model endpoint is called by the status surface.

## Evidence Requirements

- Frontend source diff.
- Rendered/source marker evidence.
- No-build evidence.
