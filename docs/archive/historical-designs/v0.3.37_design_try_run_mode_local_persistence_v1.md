## Problem

v0.3.36 makes run mode visible, but the mode can become `unknown` after refresh or remount because it is local component state.

## Boundary

- Browser localStorage only.
- Application-scoped key.
- No backend schema change.
- Explicit new run mode always overrides stored mode.

## Solution

- Add `runModeStorageKey`.
- Add `readStoredRunMode`.
- Add `persistRunMode`.
- Load mode on application id change.
- Persist mode inside `startRun(useDraft)`.

## Acceptance Criteria

- Stored draft/published values load on remount.
- New explicit run overwrites stored mode.
- Missing storage falls back to `unknown`.

## Final State

- Added `RUN_MODE_STORAGE_PREFIX`.
- Added `runModeStorageKey`.
- Added `readStoredRunMode`.
- Added `persistRunMode`.
- Added an application-id effect to restore stored mode.
- Persisted explicit draft/published mode inside `startRun(useDraft)`.
