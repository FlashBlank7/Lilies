## Problem

v0.2.67 selected cancellation/budget behavior as the next E08 gap. Lilies needed deterministic evidence that cancellation is exposed through existing API boundaries and budget violations are persisted in Platform Harness task records.

## Boundary

This design used existing APIs and Platform Harness behavior. It did not add new cancellation semantics, editable controls, frontend UI, or paid/live model calls.

## Final Design

- `scripts/v02_68_e08_cancellation_budget_behavior.py` generates cancellation and budget evidence.
- Cancellation evidence calls `POST /api/v1/runs/{run_id}/cancel` against an active runtime task boundary.
- Budget evidence starts a Platform Harness task with `max_model_calls_per_task=1`, records two model calls, and captures the failed task record.

## Acceptance

- Cancel API evidence shows an active task receives cancellation.
- Budget evidence shows a Platform Harness task fails with budget exceeded and persisted usage counts.
- Tests pass.
