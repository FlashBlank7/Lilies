# experiment-reports

本目录保存已经完成的实验报告 `.docx`。

命名格式：

`YYYY-MM-DD_HHMM_<topic>.docx`

每份报告必须包含：

1. 背景
2. 实验设计
3. 结果结论
4. 图片或截图（如有）

只有实际完成并有结果的实验才进入本目录。实验想法、实验计划和未完成结果先放在 active `docs/workingon/experiment_*.md` 或 `docs/experiment-status/backlogs/` 中；小版本归档后，active `workingon` 必须清空到 README。

如果实验结果被用于工程改进，必须在报告末尾追加“工程应用补充”，并标记：

- `已应用`：实验结果已经触发工程改进。
- `验证应用`：实验用于验证某次工程改进有效。

补充内容至少包含：应用标记、工程改进说明、原始证据、代码锚点、验证证据和剩余约束。
