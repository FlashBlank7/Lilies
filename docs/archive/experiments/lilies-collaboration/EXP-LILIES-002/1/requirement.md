# 客户需求：权限受控的 BookStack 知识助手

我们使用 BookStack 管理工厂操作、安全、财务、人力资源和公共信息。请搭建并发布
一个工作流，它从真实 BookStack 页面读取客户授权的内容，按来源版本同步知识索引，
再根据已经认证的调用者角色回答问题。

工作流必须遵守以下业务规则：

1. 未授权页面必须在检索打分之前过滤，不能进入回答上下文、引用或工件。
2. 有足够授权证据时返回简洁回答，并携带页面、页面版本和精确片段引用。
3. 没有授权证据或问题不受当前知识支持时明确拒答，不能猜测。
4. 页面更新后新答案必须引用新版本；删除后旧内容不得再被检索。
5. 重放同一同步事件不得重复建立索引或改变索引版本；旧页面版本不得覆盖新版本。
6. 标记为敏感或低证据的问题必须暂停。人工批准后才能交付；人工拒绝必须变成
   可解释的拒答。
7. 每次成功运行交付回答记录、检索与 ACL 记录、同步回执三份 JSON 工件。

客户授权的页面清单包含页面 URL、来源身份和允许角色。BookStack API 凭据作为
平台 Secret 注入，不能写在工作流草稿、工件或报告里。工作流只能读取 BookStack，
不能修改页面、用户、角色或权限。

验收会覆盖授权回答、越权拒答、公共内容、无依据问题、敏感内容人工批准和拒绝、
页面更新、删除、重复事件、旧版本冲突、引用有效性及禁止内容零泄露。
