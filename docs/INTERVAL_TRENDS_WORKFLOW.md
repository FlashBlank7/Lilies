# 区间均值趋势与样本制备

2026-09-25。从已有预测方案中提取的确定性样本方法。它回答“未来几个区间的涨跌标签究竟怎么定义”，不训练模型或声称长期预测已经有效。

项目空间的「公共工作流市场」可以加入可编辑副本；「从示例创建」有同名项目，带自编月度表、缺月份变体、Skill及修改练习。流程由输入、Python代码、输出三个现有积木组成，不调用大模型，不新增训练运行时。

## 输入与方法

选择CSV、TSV或Excel，指定周期、数值和可选对象/实际可用时刻列。每个对象每个周期一个完整周期值；高频记录须先按业务含义汇总。日、月、季使用UTC日历，月和季度按真实日历边界，不以30/90天替代。季度从一月开始。

默认历史参考为3个周期，未来3个区间，每段长度可配置。起点位于指定周期结束的下一边界；起点间隔用于控制样本数量。周期缺失不把下一行当下一周期。

1. 取起点当时已可知的历史窗口，形成滞后特征及参考均值。修订值只有实际可用时刻不晚于起点时才进入特征。
2. 第一个未来区间均值与历史参考均值比较；之后每个未来区间与前一个区间比较。
3. 差值严格大于阈值为上涨，严格小于负阈值为下跌，其余为平稳。使用原数值单位的绝对阈值，边界归平稳；小数比较使用有理数，避免浮点误差改变边界标签。
4. 标签使用输入中最新实测版本，标签可用时间取所用记录最晚的公布时刻。后续修订可改变历史标签及其可用时间，但不改变原起点的特征。
5. 缺周期、无效数值、当时尚未公布的历史或不完整的未来窗口单列原因，不填零、不缩短窗口。最后所选起点的特征单独保存，未来实测不足时仍可交给已有模型预测。

未填写可用时间时，明确假定完整周期结束即已可用；这不证明真实发布时间正确。只有一条周期记录且没有修订版本时，同样无法从文件补出历史版本。样本记录编号以表头为1，不是含换行单元格CSV的物理行号。

## 产物与后续训练

| 文件 | 用途 |
| --- | --- |
| samples.csv | 历史滞后特征、区间编号、样本标识、起点/标签可用时间和target |
| prediction-inputs.csv | 最后所选起点的特征，不含target；不是已经预测出的结果 |
| label-origins.csv | 每个标签的两个均值、差值、阈值、区间及原记录号 |
| excluded.csv | 未形成样本或标签的窗口及具体原因 |
| method.json | 配置、输入哈希、建议特征、字段映射及标签数量 |
| source.csv/tsv/xlsx | 本次原输入的独立字节快照 |
| report.md | 普通语言说明、各类数量和下载链接 |

后续训练复用现有分类能力。使用输出的`features`和`mapping`，按`origin_time`做时间划分，利用`label_available_time`排除验证起点尚未知的训练标签。不能直接沿用普通分类模板的随机划分默认值。对象标识、未来均值、变化量、原记录号不作为默认特征；相邻起点与不同区间会重叠，不是独立样本。

改阈值或窗口会创建新结果；改原表后也不会覆盖旧报告。流程不自动运行后续训练，不自动选择“最佳阈值”，不生成报价、交易或现场回写。原方案中的复杂融合及长周期模型效果不属于本流程完成范围。

## 来源与验证

来源是公司既有预测方案中明确的均值比较标签方法，属于已有设计说明，并非已复现的客户模型。原文定位和客户资料保留本地私有目录。公共样例完全自编，不含客户数值、字段或阈值。

- 自编测试覆盖标签均值、三类边界、小数、零/负值、日/月/季日历、迟到与修订、多个对象、重复记录、缺字段/周期、空未来窗口、Excel多表及输入快照。未来数值变化不得改变历史特征。
- 独立模拟员工从页面创建项目，直接运行得到90个标签；阈值0.5改为1后平稳标签21→45。负阈值运行失败，显示具体原因，修复后成功。
- 员工在代码积木中保存结果说明改动，草稿r1→r2；通过文件选择器换缺少一个月的变体，原流程得到71个标签和25项排除说明。该变体由开发接口上传，页面完成选择与运行；不把这次操作称为原生文件选择器上传验收。
- 对三次成功运行的251个标签和所有滞后值独立按原记录复算，21份产物下载通过；旧结果仍能读取。页面完成桌面下载和390×844下修复、运行及下载。没有模型调用或真实员工参与，不以此代替长期模型泛化验收。
