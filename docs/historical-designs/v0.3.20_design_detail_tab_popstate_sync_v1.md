## Problem

If tab clicks push URL state but the page does not listen to browser history, back/forward will change the URL without changing the visible tab.

## Boundary

- Only respond to known `tab` values.
- Do not reload the page.
- Do not disturb build event polling cleanup.

## Solution

- Add a `popstate` listener that reads `?tab=`.
- Update the React tab state only when the URL contains a valid tab.
- Keep invalid tab values ignored.

## Acceptance Criteria

- Browser back/forward can restore a previous valid tab.
- Invalid tab query values do not change state.
- The listener is removed on unmount.
