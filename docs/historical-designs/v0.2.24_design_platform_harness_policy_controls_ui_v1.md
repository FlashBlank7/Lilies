## 1. Goal

Expose Platform Harness policy controls in the Studio monitor tab so maintainers can inspect stdio MCP blocked reasons without reading backend logs.

## 2. Module Boundary

Frontend:

- `platform/frontend/lib/platform.ts`
- `platform/frontend/lib/i18n.ts`
- `platform/frontend/app/applications/[id]/page.tsx`
- `platform/frontend/app/globals.css`

## 3. Implementation Plan

1. Add TypeScript types for the policy controls API.
2. Fetch policy controls on page load and on monitor refresh.
3. Render a compact policy panel above task/benchmark history:
   - network policy
   - allowlist
   - secret policy state
   - worker lease default
   - stdio MCP support flags
   - decision cards with allowed/blocked status and operator action
4. Add Chinese and English copy through `i18n.ts`.
5. Keep UI quiet and operational; do not turn it into a marketing page.

## 4. Acceptance Criteria

- Monitor tab shows policy controls even when no workflow run exists. Completed.
- Blocked stdio allowlist path is visually distinguishable from allowed paths. Completed.
- Long reason text wraps inside the panel. Completed.
- Frontend lint/build pass. Completed.
