## Problem

A readiness score is not enough; users need concrete missing-detail hints before save/build.

## Boundary

- Hints must be deterministic local text.
- Hints must not overwrite the prompt.

## Solution

- Show one compact item per signal.
- Mark each item ready or needs detail.
- Keep labels short enough for the create card.

## Acceptance Criteria

- Missing signals are visible.
- Ready signals are visibly distinct.
- Requirement text remains editable.
