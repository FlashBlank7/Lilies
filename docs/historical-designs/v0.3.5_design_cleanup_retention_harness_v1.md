## Problem

After the smoke-cleanup API exists, retention evidence should prove the boundary works rather than only listing smoke apps. The harness must avoid touching non-smoke applications.

## Boundary

The harness may create and delete one dedicated `v0.3.5-smoke` app. It must not delete pre-existing smoke apps unless explicitly requested, and must never delete a non-smoke app.

## Solution

Add a v0.3.5 evidence script that:

- creates one dedicated `v0.3.5-smoke` app,
- runs dry-run cleanup,
- runs actual cleanup,
- verifies the app is gone,
- verifies a non-smoke app would be rejected in static tests,
- records no build calls.

## Acceptance Criteria

- Live cleanup evidence passes.
- Static focused tests cover dry-run response shape and non-smoke rejection through API tests.
- Evidence records created app id, dry-run, delete, and gone checks.
- No build endpoint is called.

## Evidence Requirements

- v0.3.5 JSON evidence.
- Focused pytest command.
- Remaining cleanup limitations in stage report.
