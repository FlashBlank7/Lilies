## Problem

v0.2.22 and v0.2.24 already established the safe blocking and visibility behavior. v0.2.106 must build on that work instead of erasing it.

## Boundary

- v0.2.22 restricted-policy blocking remains valid for undeclared or unsandboxed stdio.
- v0.2.24 policy-controls visibility remains the operator surface.
- Only the allowlist-grade sandboxed and declared-host scenario changes from blocked to allowed.

## Final Scheme

The implementation preserves old blocked cases and adds a new allowed contract. Generated evidence maps the old stages to the new behavior.

## Acceptance

- Existing full/full and sandboxed no-network tests still pass.
- Restricted undeclared stdio remains blocked.
- Policy controls now distinguish supported sandboxed allowlist from unsupported undeclared/unsandboxed use.
