## Problem

v0.3.6 proved that the application detail route is reachable, but reachability is not enough. A non-technical user who opens a generated or safe draft still has to infer what the canvas, side panels, tests, run state, and monitoring mean.

## Boundary

This stage should not redesign the full studio or add a long tutorial. The orientation must stay compact, operational, and tied to the current draft state.

## Solution

Add a first-run guidance surface in the detail view that summarizes:

- current workflow structure,
- acceptance readiness,
- run readiness,
- monitoring evidence.

The surface should be visible near the existing canvas guidance and use stable `data-detail-guidance` markers so persona harnesses can verify it without relying on screenshots.

## Acceptance Criteria

- Detail route source contains explicit first-run guidance markers.
- Guidance is local to the studio detail view.
- Copy exists in Chinese and English.
- Layout remains responsive and does not hide the canvas on desktop.
