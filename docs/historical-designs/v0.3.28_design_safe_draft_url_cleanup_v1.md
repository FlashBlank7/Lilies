状态：completed

## Source

- Source stage report: `docs/stage-reports/v0.3.27_safe_draft_landing_handoff.md`
- Source tasks:
  - `Clear only safeDraft URL state`

## Problem

After acknowledgement, the URL should stop claiming a fresh safe-draft landing while preserving useful state such as the active tab.

## Boundary

- Use `window.history.replaceState`.
- Delete only `safeDraft`.
- Preserve `tab`, `build`, and any other unrelated query params.

## Solution

- Add `dismissSafeDraftLanding`.
- Parse current URL search params, delete `safeDraft`, then replace the URL.
- Preserve the existing path and remaining query params.

## Acceptance Criteria

- `safeDraft` is removed.
- `tab` is preserved.
- No navigation reload is required.

## Final State

- URL cleanup uses `URLSearchParams`, `query.delete('safeDraft')`, and `window.history.replaceState`.
- Remaining query parameters are preserved.
- No reload or backend request is required.
- Verification is archived in `docs/workingon-archives/v0.3.28/safe_draft_dismissal_v0.3.28.json`.
