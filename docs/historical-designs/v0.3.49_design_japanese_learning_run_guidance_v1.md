## Problem

Even with a customer-facing Run tab, the Japanese learning scenario needs domain-specific guidance: what to enter, what steps are expected, and what "data flow" means for comment-expression extraction.

## Boundary

- Use scenario detection from requirement/name/node labels.
- Do not hide the general Run tab behavior for other workflows.
- Do not invent runtime evidence.

## Proposed Solution

- Add a scenario hint panel on Run when the workflow matches Japanese learning.
- Add Japanese-topic guidance near the start controls.
- Add fallback step labels for collecting comments, extracting expressions, and generating a daily summary when scenario terms are present.

## Acceptance Criteria

- Run tab shows scenario-specific guidance for Japanese learning workflows.
- Topic input expectation is visible before raw payload.
- Progress wording aligns with the scenario without overclaiming execution.

## Final State

- Completed in `v0.3.49`.
- The Run tab detects Japanese-learning workflow text from requirement, description, name, and node content.
- Matching workflows show scenario guidance, topic input help, and learning-specific step labels while preserving raw payload and actual run-event evidence boundaries.
