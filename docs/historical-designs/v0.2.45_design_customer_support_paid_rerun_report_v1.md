## Problem

After the v0.2.44 deterministic repair, Lilies still needed a bounded paid/live rerun to verify whether customer-support Template reuse behavior had materially improved, and whether the earlier shallow/deep failures were fixed or only shifted.

## Boundary

- In scope: run the paid/live `customer_support_router` E05 rerun, compare `none` / `shallow` / `deep`, generate JSON + chart + DOCX, and update the experiment index and ledger.
- Out of scope: fixing deep long-chain deadline behavior, expanding to more task families, or adding UI/API visibility for Builder deadline controls.

## Final Design

Use the existing `scripts/e05_template_reuse_depth_experiment.py` runner with a bounded envelope:

- case: `customer_support_router`
- version: `v0.2.45`
- max turns: `42`
- max repair cycles: `2`
- build deadline: `600s`
- provider timeout: `180s`
- run timeout: `900s`

Report the outcome through three artifacts:

1. raw JSON for exact replay/debug,
2. compact summary/chart for routine review,
3. concise DOCX for formal experiment closure and human reading.

## Acceptance

- Paid/live evidence exists or a concrete blocker is recorded.
- The result compares v0.2.45 against v0.2.43 without overclaiming.
- The experiment ledger records whether v0.2.44 is validated, partially validated, or not validated.
- Regression evidence is preserved alongside the experiment artifacts.
