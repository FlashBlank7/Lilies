## Final Contract

`PATCH /api/v1/platform/harness/policy-controls` updates process-local Platform Harness policy controls and returns `before`, `after`, and `audit`.

Mutable controls:

- `network_egress_policy`
- `network_egress_allowlist`
- `cancellation_policy`
- `secret_policy_enabled`
- `worker_lease_seconds`
- task and owner budget `limits`

## Enforcement

- Empty patch rejected.
- Blank allowlist host rejected.
- Negative limit rejected.
- `cancellation_policy=disabled` blocks workflow run cancellation.
- Audit includes changed fields, reason, and `not_full_sidecar_completion`.
