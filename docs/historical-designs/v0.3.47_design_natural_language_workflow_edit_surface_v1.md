## Problem

The current feature is framed as "natural-language draft edit" and visually lives under the node inspector. That makes it feel like a narrow per-brick trick instead of a workflow-level editing surface.

## Boundary

- Rename and reposition the existing preview/apply mechanism as workflow-level editing.
- Keep preview non-destructive until explicit apply.
- Do not remove advanced per-node JSON editing.

## Proposed Solution

- Add a workflow-level edit dialog section before the node inspector details.
- Rename copy to "自然语言工作流编辑" / "Natural-language workflow edit".
- Send referenced brick ids with preview requests.
- Present references as context only, not as a modification boundary.

## Acceptance Criteria

- The UI no longer says "自然语言修改草稿" / "Natural-language draft edit".
- The edit panel is marked as workflow-level with `data-workflow-edit-dialog`.
- Preview requests include `reference_node_ids`.
- The apply flow remains explicit and non-destructive until confirmed.
