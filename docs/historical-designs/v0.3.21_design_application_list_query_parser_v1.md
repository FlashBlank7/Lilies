## Problem

The app list has filters, search, and sort, but a shared or returned URL cannot restore those controls.

## Boundary

- Only parse `filter`, `q`, and `sort`.
- Ignore invalid filter/sort values.
- No backend changes.

## Solution

- Add allowlists for app filters and sort modes.
- Add guards for query values.
- Hydrate app-list state from the current URL and from browser back/forward.

## Acceptance Criteria

- Valid query values restore controls.
- Invalid query values are ignored.
- Popstate can restore list controls without reloading.
