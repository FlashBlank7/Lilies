## Problem

The create card now explains the next action, but users still have to map that explanation back to the right control.

## Boundary

- Use local state only for deciding the recommended affordance.
- Do not remove the existing explicit Save Draft and Start Team controls.
- Do not call backend endpoints when the recommendation is to add more detail.

## Solution

- Add a recommended-action strip under the action explainer.
- Map add-detail and improve states to focusing the requirement textarea.
- Map save-draft-ready state to the existing safe draft creation function.
- Show busy state as a disabled recommendation.

## Acceptance Criteria

- Recommended action has deterministic labels and targets for all create action states.
- Add-detail and improve states focus the requirement textarea.
- Save-draft state uses the existing safe draft path.

## Final State

- Implemented in `platform/frontend/app/page.tsx` as `recommendedCreateAction` and `runRecommendedCreateAction`.
- Added `data-recommended-create-action` and `data-recommended-action-target` markers.
- Save-draft recommendation uses the existing `saveDraftOnly` safe draft path.
- Verification is recorded by `scripts/v03_26_recommended_create_action.py` and `tests/test_v03_26_recommended_create_action.py`.
