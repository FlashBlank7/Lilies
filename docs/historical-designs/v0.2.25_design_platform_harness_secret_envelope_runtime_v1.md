## 3. Implementation Plan

1. Add envelope decrypt logic to `PlatformHarness`.
2. Resolve encrypted rows to plaintext only at injection boundary.
3. Leave legacy plaintext rows readable.
4. Raise `PlatformHarnessViolation` if an encrypted row cannot be authenticated/decrypted.
5. Keep existing redaction behavior unchanged.

- `inject_secret_references()` returns the original plaintext for encrypted rows. Completed.
- Legacy rows without the envelope prefix still resolve. Completed.
