## Problem

The E02 human-panel protocol names raw evidence and readable TestFrame packets, but the participant-facing packet files are not present in the execution package. That leaves the external panel operationally underspecified even though protocol, capture schema, checklist, and analyzer already exist.

## Scope

Add a versioned `packets/` set under `docs/experiment-status/e02-human-panel/`:

- raw JSON task packet,
- readable TestFrame task packet,
- facilitator manifest,
- facilitator-only answer key,
- post-task questionnaire.

The packets must reference the existing v0.2.36 real evidence and must not invent participant rows.

## Acceptance

- Packet directory exists with all required files.
- Both task packets share the same task prompt and output fields.
- Manifest defines counterbalanced order A/B.
- Answer key is facilitator-only and not embedded in participant packets.
- Evidence script and tests prove the packet set exists and that E02 remains incomplete until real participant rows exist.

## Boundary

This version completes the in-repo packet-material gap only. It does not execute sessions, recruit participants, or close E02.
