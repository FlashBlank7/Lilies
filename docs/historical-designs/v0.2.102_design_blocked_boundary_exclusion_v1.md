## Problem

The reselection step must not turn externally blocked experiments into automatic work. E02 and E10 are legitimate experiments, but their current blockers cannot be removed by local automation alone.

## Boundary

- E02 true human timing requires recruited participants and a timing protocol.
- E10 governed memory requires accepted permission, audit, revoke, retention, and source-attribution scope.
- If a blocked lane is present in the candidate set, its score must be non-winning.
- A blocked lane can be documented but not selected as the next implementation lane.

## Final Scheme

Represent hard blockers explicitly in the selector output. Tests should check both lane presence and non-selection, so the system does not hide blocked work or accidentally advance it.

## Acceptance

- E02 and E10 appear in the candidate evidence.
- E02 and E10 are marked blocked.
- The selected lane is not in the blocked candidate set.
