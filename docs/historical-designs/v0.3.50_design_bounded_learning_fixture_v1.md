## Problem

The Japanese-learning workflow is now understandable, but it still relies on placeholder comments and does not make the bounded validation source explicit. A user can reasonably expect proof of the result shape before real external video-comment collection is implemented.

## Boundary

- Use a controlled offline sample comment set.
- Do not claim live scraping or real external-video evidence.
- Keep the workflow no-model and runnable as a safe draft.

## Proposed Solution

- Add a controlled comment fixture to the Japanese-learning safe draft template.
- Include common Japanese spoken expressions such as `それな`, `ワンチャン`, and `普通に助かる`.
- Display a UI note that this validates result shape with a controlled fixture, not live external collection.

## Acceptance Criteria

- The safe draft contains a controlled sample comment context.
- The Run tab explains the bounded fixture boundary.
- The evidence harness verifies that no external collection is claimed.

## Final State

- Completed in `v0.3.50`.

- The fixture includes `それな`, `ワンチャン`, and `普通に助かる`.
