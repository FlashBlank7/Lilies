## Problem

URL-restored app-list views can be narrow or empty, but users do not get a compact explanation of what state is active.

## Boundary

- Use existing app-list state only.
- No backend changes.
- Keep the summary compact and scannable.

## Solution

- Add a visible list-state summary below the search/sort controls.
- Show visible count, total count, active filter, search text, and sort mode.
- Mark it with a stable data attribute for regression coverage.

## Acceptance Criteria

- Summary is visible when apps exist.
- Summary reflects filter/search/sort state.
- Copy is bilingual.
