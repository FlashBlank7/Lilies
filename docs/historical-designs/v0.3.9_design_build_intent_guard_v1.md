## Problem

Build actions can start model/team work. Non-technical users may click a primary action while they only want to inspect a draft, causing time or cost surprises.

## Boundary

Do not remove build capability. Add a lightweight intent guard before calling `/builds`.

## Solution

- Add a two-step confirmation state for home primary build creation.
- Add a two-step confirmation state for detail-page Start Team.
- Keep safe draft creation as the direct low-risk path.
- Add stable `data-build-intent` and `data-build-action` markers.

## Acceptance Criteria

- First click arms build intent instead of calling `/builds`.
- Second click performs the existing build action.
- Safe draft remains available without confirmation.
- Source/rendered markers verify guarded state.

## Evidence Requirements

- Frontend source diff.
- v0.3.9 harness JSON.
- Focused tests.
