## Problem

The E02 package is ready, but real execution still needs a reliable way to validate participant result rows and compute the analysis summary required to close the blocker. Without tooling, real participant data could be inconsistent, incomplete, or hard to interpret.

## Tasks

1. Add a reusable analyzer for E02 result CSV files.
2. Validate required schema fields and one raw/readable row per participant.
3. Compute median timing, correctness rate, actionability rate, and intervention counts.
4. Generate a markdown analysis summary from captured rows.

## Acceptance

- Analyzer rejects incomplete or unpaired participant rows.
- Analyzer reports when zero real participant rows are captured.
- Analyzer can produce a summary for valid data.
- Analyzer never treats bundled tests or fixtures as E02 completion evidence.
