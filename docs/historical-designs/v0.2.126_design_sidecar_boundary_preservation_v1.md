## Problem

Production worker supervision is a real sidecar architecture slice, but it must not be used to claim distributed queue semantics, provider-backed KMS, external process management, or full Platform Harness sidecar completion.

## Boundary

- The supervisor is an in-process worker loop manager.
- It consumes the existing harness task store and existing handlers.
- It does not implement a distributed queue backend.
- It does not manage OS-level worker processes.
- It does not change external KMS behavior.

## Acceptance

- Snapshot exposes explicit false boundary flags for distributed queue semantics, external process manager, external KMS integration, and full sidecar completion.
- Stage report and ledger keep remaining architecture gaps explicit.
