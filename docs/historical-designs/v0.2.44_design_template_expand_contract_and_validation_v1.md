## 1. Goal

Make Builder `template_expand` return enough contract and validation information for the Builder Team to preserve the template architecture after expansion.

## 2. Module Boundary

Primary files:

- `platform/backend/src/agent_platform/builder.py`
- `tests/test_workflow.py`

Read-only dependencies:

- `platform/backend/src/agent_platform/template_store.py`
- `templates/customer_support_router.json`
- `platform/backend/src/agent_platform/blocks.py`

## 3. Implementation Plan

1. After `template_expand`, validate the resulting draft and include validation summary in the tool result.
2. Include expanded node types and edge count in the tool result.
3. For marketplace templates, include template contract fields such as `min_blocks_required`, expected inputs, expected outputs, category, and confidence.
4. Add deterministic coverage for `customer_support_router` marketplace expansion result.

## 4. Acceptance Criteria

- Customer-support marketplace `template_expand` returns `source=marketplace`: covered by `test_builder_customer_support_template_expand_returns_contract_and_validation`.
- Result includes `validation.valid=true` for direct expansion: covered by the same test.
- Result includes node types containing `question_classifier`, `if_else`, `template_transform`, `end`: covered by the same test.
- Result includes template contract `min_blocks_required` containing `if_else`: covered by the same test.
