## Problem

The word cancel can mean dismiss, stop waiting, or stop the underlying run. The Try result card must explain that cancellation stops the current run and that waiting is still safe.

## Boundary

- Copy and local UI state only.
- Do not change run status semantics.
- Do not hide the active status or duplicate-start guard.

## Solution

- Add cancel intent text near the confirmation panel.
- Label the destructive second-step action clearly.
- Label the non-destructive dismissal action as keep waiting.

## Acceptance Criteria

- Copy distinguishes stopping the current run from merely closing UI.
- Copy tells users they can keep waiting.
- Guidance does not suggest starting another run while active.
