# design_builder_benchmark_v1

## 1. Goal

建立 Builder benchmark v1，让 Builder 能力边界从 demo 直觉转成可回归的结构指标。

## 2. Module Boundary

候选模块：

- `platform/backend/src/agent_platform/builder_benchmark.py`
- `platform/backend/src/agent_platform/api.py`
- `tests/test_workflow.py`

## 3. Data Flow

BenchmarkCase -> Builder run 或 deterministic candidate workflow -> structural scoring -> report with node type coverage, required tool nodes, test frame coverage, harness presence。

## 4. Implementation Plan

1. 先做 deterministic scoring，不调用付费模型。
2. 支持输入 reference workflow 和 candidate workflow。
3. 输出结构指标：
   - required node type coverage
   - required tool node coverage
   - edge count delta
   - required harness coverage
   - test count / readable frame coverage
4. 后续再接真实 Builder run。

## 5. Acceptance Criteria

- 可以在不调用 LLM 的情况下评估一个 candidate WorkflowSpec。
- API 或内部函数返回可读 benchmark report。
- focused tests 覆盖 perfect / missing harness 两类结果。
