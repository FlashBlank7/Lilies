## Problem

Empty selection, edge selection, and node selection currently feel similar. Users need to know what they selected and what is safe to do next.

## Boundary

Do not alter canvas interaction behavior. Add contextual copy and layout cues.

## Solution

- Show empty-selection guidance when no node/edge is selected.
- Show edge-selection guidance when an edge is selected.
- Show a safe edit guide when a node is selected.

## Acceptance Criteria

- Empty, edge, and node states have separate visible copy.
- Delete/raw JSON actions are framed as advanced changes.
- Existing edit controls still work.
