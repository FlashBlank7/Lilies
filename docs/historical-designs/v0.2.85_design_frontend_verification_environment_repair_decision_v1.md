## Source

## Problem

Frontend verification has repeatedly failed because `node` and `npm` are unavailable, despite `platform/frontend/node_modules` and lockfile being present. The productization path should explicitly choose environment repair as the next unit of work.

## Boundary

- Detect current Node/npm availability.
- Do not install or mutate toolchains in this decision version.
- Carry an actionable repair target to the next stage.

## Design

- Record command availability for `node`, `npm`, and package-manager candidates.
- Select a next stage that repairs local Node/npm availability or introduces a repo-local frontend verification runner.

## Acceptance

- Decision evidence records missing `node` and `npm`.
- Next-stage task explicitly targets frontend verification environment repair.

Completed in v0.2.85.
