## Problem

Status filters help narrow readiness, but returning users still need to scan long lists to find a specific app by name or description.

## Boundary

- Use existing application list data only.
- No backend endpoint changes.
- Keep search compatible with status filters.

## Solution

- Add a search input to the app-list controls.
- Filter the status-filtered app set by name and description.
- Add filtered empty-state copy.

## Acceptance Criteria

- Search applies together with status filter.
- Search has bilingual copy and stable markers.
- Empty search results explain how to recover.
