## 1. Goal

Encrypt newly saved Platform Harness secrets before persistence.

## 2. Module Boundary

Backend:

- `platform/backend/src/agent_platform/config.py`
- `platform/backend/src/agent_platform/api.py`
- `platform/backend/src/agent_platform/platform_harness.py`

## 3. Implementation Plan

1. Add `platform_harness_secret_envelope_key` to settings with `repr=False`.
2. Pass the explicit envelope key, or API token fallback, into `PlatformHarness`.
3. Add a versioned envelope format stored inside the existing `platform_secrets.value` column.
4. Use standard-library authenticated encryption:
   - PBKDF2-HMAC-SHA256 derives encryption and MAC keys.
   - HMAC-SHA256 keystream encrypts plaintext by XOR.
   - HMAC-SHA256 authenticates the envelope.
5. Add public secret metadata indicating encrypted or legacy storage mode.
