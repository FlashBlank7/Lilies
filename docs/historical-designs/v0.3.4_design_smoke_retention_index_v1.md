## Problem

Automatic evolution now creates local smoke applications for v0.3.2 and v0.3.3. There is no application delete/archive API, so cleanup cannot be implemented honestly yet. But untracked accumulation is also not acceptable.

## Boundary

This design does not delete or mutate applications. It creates a retention index that lists smoke apps by marker and records the cleanup limitation as a deferred P0/P1 ledger item with reason.

## Solution

Extend the v0.3.4 evidence script to:

- list applications through the local API,
- identify smoke apps by `v0.3.x-smoke` markers in name or requirement,
- group them by marker,
- record counts, latest ids, and retention policy,
- emit a bug ledger for browser evidence and smoke retention.

## Acceptance Criteria

- Smoke apps are discoverable by marker.
- Evidence records counts and latest ids.
- No delete/archive is attempted.
- P0/P1 ledger has no open item without fix/defer reason.
- Next-stage cleanup/archive task is defined in the stage report.

## Evidence Requirements

- v0.3.4 JSON evidence.
- Focused pytest command.
- Retention policy in stage report.
