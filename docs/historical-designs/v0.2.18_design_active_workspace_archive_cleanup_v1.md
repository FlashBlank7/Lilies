# design_active_workspace_archive_cleanup_v1

## 1. Goal

实现新的归档语义：

- 小版本归档时，`current-design/` 中的 design 必须归档到 `historical-designs/`。
- 小版本归档时，`workingon/` 中间结果必须按版本归档。
- 下一次演进开始时，`current-design/` 和 `workingon/` 只保留 active workspace README，不保留中间文件。
- 实验报告和实验原始证据从 `workingon/` 转入 `experiment-status/`。

## 2. Module Boundary

本设计只调整文档目录和 archive 规则，不修改后端运行时代码。

涉及目录：

- `docs/current-design/`
- `docs/historical-designs/`
- `docs/workingon/`
- `docs/workingon-archives/`
- `docs/experiment-status/`
- `docs/stage-reports/`

## 3. Data Flow

`current-design/design_*.md`
-> `docs/historical-designs/v<version>_design_<topic>.md`
-> active `current-design/` 清空到 README。

`workingon/*`
-> `docs/workingon-archives/v<version>/`
-> active `workingon/` 清空到 README。

`workingon/experiment-reports/*.docx`
-> `docs/experiment-status/reports/`

`workingon/experiment_*.json`
-> `docs/experiment-status/evidence/`

## 4. Implementation Plan

- 创建 `docs/workingon-archives/README.md`。
- 将现有 workingon 中间文件按版本移动到 `docs/workingon-archives/`。
- 将实验报告和原始证据移动到 `docs/experiment-status/`。
- 删除 active `current-design/design_*.md`，保留 README。
- 更新 active README，说明目录为空时才可以开始新 stage。
- 创建 v0.2.18 stage report，记录本次归档。

## 5. Acceptance Criteria

- `docs/current-design/` 只剩 README。
- `docs/workingon/` 只剩 README。
- 每个历史 design 有版本化归档记录。
- workingon 中间结果有版本化 archive。
- stage report 记录 design archive 和 workingon archive。
- `git status --short` 只显示预期变更和既有无关未跟踪文件。
