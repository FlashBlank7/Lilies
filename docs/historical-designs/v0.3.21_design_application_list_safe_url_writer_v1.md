## Problem

Changing filter/search/sort should keep the URL truthful, but URL writes must not spam browser history while typing or call backend write endpoints.

## Boundary

- Use browser history only.
- Preserve unrelated query parameters.
- Remove default values from the URL: `filter=all`, `sort=readiness`, and empty search.

## Solution

- Add `writeAppListUrlState`.
- Add specific setters for filter, search, and sort.
- Use `pushState` for filter/sort changes and `replaceState` for search typing.

## Acceptance Criteria

- Filter/sort changes push shareable URL state.
- Search typing replaces URL state.
- Defaults keep the URL compact.
