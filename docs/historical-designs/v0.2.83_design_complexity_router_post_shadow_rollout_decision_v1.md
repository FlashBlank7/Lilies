## Problem

v0.2.82 completed stage-0 shadow-only rollout with clean metrics, but E07 is not yet productized as a default or operator-controlled workflow. The next stage must choose whether to execute operator opt-in, keep observing shadow-only, or begin default enablement review.

## Boundary

- Decide the next rollout path only.
- Do not execute stage-1 in this version.
- Do not enable default routing.
- Prefer a path that advances productization without bypassing rollout evidence.

## Design

- Load v0.2.82 shadow-only evidence and v0.2.80 staged rollout plan.
- Score options by productization value, safety, evidence readiness, and behavior-change risk.
- Select `execute_operator_opt_in_rollout` if stage-0 passed and stage-1 exists with `behavior_change=false`.
- Reject immediate default enablement review while operator opt-in evidence and frontend verification are still missing.

## Acceptance

- Decision evidence selects one post-shadow option.
- Tests verify selected and rejected alternatives.
- Next stage points to operator opt-in rollout execution.
