## Problem

Studio showed generic policy settings, but it did not display the E08 soft passmode versus hard Platform Harness boundary distinction.

## Boundary

This stage added a compact read-only Studio surface inside the existing monitor policy-controls panel. It did not add policy editing or a new route.

## Final Design

- `PlatformPolicyControls` includes `e08_boundary`.
- The monitor policy-controls section renders current slice, soft passmode, hard boundary, control statuses, source path, and not-full-sidecar marker.
- zh/en labels and compact CSS were added.

## Acceptance

- Studio has a visible E08 boundary panel when policy controls load.
- Text does not imply full sidecar completion.
- Frontend changes are narrow and type-shaped against the new API field.
