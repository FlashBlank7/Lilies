## Problem

v0.2.65 exposed E08 boundary language, but operators still needed a compact behavior matrix comparing soft passmode, cancellation, budget, worker lease, and hard policy controls.

## Boundary

This design added read-only behavior classification. It did not add new enforcement, editable controls, or full sidecar completion.

## Final Design

- `e08_boundary.behavior_matrix` is returned by the policy-controls API.
- Rows cover `workflow_passmode`, `cancellation_checkpoint`, `budget_limits`, `worker_lease`, `network_egress_policy`, and `secret_policy`.
- Each row records layer, enforcement, status, signal, and source.

## Acceptance

- API returns `e08_boundary.behavior_matrix`.
- Matrix rows cover soft passmode, cancellation, budget, worker lease, and hard policy.
- Focused tests pass.
