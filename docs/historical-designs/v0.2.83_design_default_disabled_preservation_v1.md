# design_v0_2_83_default_disabled_preservation

## Source

- Source stage report: `docs/stage-reports/v0.2.82_complexity_router_shadow_only_rollout.md`
- Source task: `Preserve default-disabled status`
- Version target: `v0.2.83_complexity_router_post_shadow_rollout_decision`

## Problem

Moving toward productization must not be mistaken for enabling the router as default behavior.

## Boundary

- Preserve `default_enabled=false`.
- Keep default enablement as an explicit later stage-report decision.
- Record the difference between `allowed_to_enable_default` and actual default state.

## Design

- Include default-safety status in the decision evidence.
- Require any selected path before default enablement to have `behavior_change=false`.

## Acceptance

- Evidence records `default_enabled=false`.
- Selected next path does not change runtime behavior.

## Status

Completed in v0.2.83.
