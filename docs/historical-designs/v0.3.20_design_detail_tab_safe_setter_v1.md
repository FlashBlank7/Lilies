## Problem

v0.3.19 lets card quick actions open a detail tab via `?tab=`, but tab clicks inside the detail page still call `setTab` directly and leave the URL stale.

## Boundary

- Do not call build, test, run, publish, or restore APIs from tab synchronization.
- Preserve existing `?build=` query behavior.
- Keep tab ids restricted to `STUDIO_TABS`.

## Solution

- Add `setStudioTab(next, options)` as the single UI tab setter.
- Update `?tab=` with `history.pushState` for user navigation.
- Use `history.replaceState` for programmatic build-watch tab selection.
- Preserve existing query parameters such as `build`.

## Acceptance Criteria

- Panel tab buttons, debug-draft, node selection, build-watch, run-start, and next-action buttons use the helper.
- `?build=` survives tab URL updates.
- Tab synchronization does not call unsafe endpoints.
