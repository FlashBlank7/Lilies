## Problem

Users need to know whether the next action is filling a required field, fixing JSON, or returning to the input form. The error should point them back to the editable controls, not only describe the failure.

## Boundary

- Copy and local focus action only.
- Do not infer a field-specific highlight beyond the parser message.
- Do not auto-fill or mutate inputs.

## Solution

- Add concise correction guidance beside the parser error.
- Add a focus action that returns to the input form.
- Keep the JSON preview visible below/near the error context.

## Acceptance Criteria

- Guidance points users to the input form and preview.
- Focus action does not call an API.
- Guidance works for required, numeric, and JSON parse errors.
