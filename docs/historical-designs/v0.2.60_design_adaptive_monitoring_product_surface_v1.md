## Problem

E05 adaptive Template policy had a deterministic monitoring snapshot but no product-visible API or Studio surface. Operators needed a quick way to see adaptive health, critical alerts, override visibility, and family coverage.

## Boundary

- In scope: read-only API and Studio monitor display over existing evidence.
- In scope: missing-evidence fallback.
- Out of scope: scheduled drift checks, persistence, alert delivery, or changing adaptive policy behavior.

## Final Design

`agent_platform.adaptive_monitoring` normalizes the current monitoring snapshot and classifies it as `healthy`, `attention`, or `missing_evidence`. `GET /api/v1/templates/adaptive-monitoring` exposes that payload. Studio's monitor tab fetches it alongside existing platform tasks, policy controls, and benchmark history, then renders compact status and case cards.

## Acceptance

- API returns current status and monitored cases.
- Missing evidence returns `missing_evidence`.
- Studio monitor tab includes adaptive policy status.
- Backend regression passes.
