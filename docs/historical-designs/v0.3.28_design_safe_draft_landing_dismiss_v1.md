## Problem

The safe-draft landing banner remains visible as long as `safeDraft=1` stays in the URL, even after users understand it.

## Boundary

- Local UI state only.
- No backend calls.
- Do not remove the safe-draft next-step actions.

## Solution

- Add a dismiss button inside the safe-draft landing action row.
- Hide the banner immediately after acknowledgement.
- Keep the button `type="button"`.

## Acceptance Criteria

- Dismiss button has stable source markers.
- Dismiss hides `safeDraftLanding`.
- Dismiss performs no backend action.

## Final State

- Implemented in `platform/frontend/app/applications/[id]/page.tsx` as `dismissSafeDraftLanding`.
- Added `data-safe-draft-action="dismiss"` with `type="button"`.
- Dismiss sets `safeDraftLanding` to false and performs no backend call.
- Verification is recorded by `scripts/v03_28_safe_draft_dismissal.py` and `tests/test_v03_28_safe_draft_dismissal.py`.
