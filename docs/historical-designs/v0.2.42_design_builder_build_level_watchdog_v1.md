## 1. Goal

Add an optional whole-build elapsed-time boundary for Builder builds.

This boundary should distinguish build-level timeout from provider stream timeout. If the build exceeds the requested elapsed-time budget, it should enter `needs_attention`, finish the Platform Harness task as failed, and expose structured failure metadata.

## 3. Data Flow / Control Flow

Current chain:

1. Client creates Builder build with `max_turns` and `max_repair_cycles`.
2. Builder task starts in Platform Harness with those budgets.
3. Individual model stream timeouts can be observed after v0.2.40.
4. Whole-build elapsed duration is not an explicit task boundary.

Target chain:

1. Client may create Builder build with `max_elapsed_seconds`.
2. Build storage persists the optional deadline.
3. Builder includes it in Platform Harness task metadata and emits `build.deadline.configured`.
4. Builder wraps the coordinator build loop in an `asyncio.timeout()` boundary when the value is present.
5. On timeout, Builder emits `build.deadline.exceeded`, updates build to `needs_attention`, and finishes Harness task failed with `failure.type=build_timeout`.

## 4. Implementation Plan

1. Add optional `max_elapsed_seconds` to `BuildRequest`.
2. Add `max_elapsed_seconds` column migration for `builds`.
3. Pass the value through `create_build()` and API.
4. Add `BuildDeadlineExceeded` error type in `builder.py`.
5. Wrap the top-level `_agent_loop()` call in a build-level timeout when configured.
6. Include deadline/progress metadata in build events and Harness task metadata.
7. Extend `_failure_metadata()` for `BuildDeadlineExceeded`.
8. Add deterministic test using a slow provider and tiny `max_elapsed_seconds`.

## 5. Acceptance Criteria

- Old build requests without `max_elapsed_seconds` still work.
- New build requests with tiny deadline enter `needs_attention` deterministically.
- Build error indicates whole-build timeout, not provider stream timeout.
- Platform Harness task metadata contains `failure.type=build_timeout`, `timeout_like=true`, and deadline values.
- Stream contains `build.deadline.configured` and `build.deadline.exceeded`.
- Full backend regression passes.
