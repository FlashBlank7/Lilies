## Problem

Operators need a product surface for queue semantics rather than only low-level task and lease APIs.

## API Surface

- `GET /api/v1/platform/harness/queue-semantics`
- `POST /api/v1/platform/harness/queue/requeue-expired`

## Acceptance

- Snapshot exposes queue mode, queued/running/terminal counts, active workers, stale workers, and boundary flags.
- Requeue endpoint returns the tasks requeued due to expired worker lease.
- Existing task/lease APIs remain available.
