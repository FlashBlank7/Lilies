# design_v0_2_82_default_disabled_preservation

## Source

- Source stage report: `docs/stage-reports/v0.2.81_complexity_router_staged_rollout_execution_decision.md`
- Source task: `Preserve default-disabled status`
- Version target: `v0.2.82_complexity_router_shadow_only_rollout`

## Problem

Shadow-only rollout evidence could be misread as production routing enablement. The version must preserve the distinction between eligibility for later review and actual default state.

## Boundary

- Keep `default_enabled=false`.
- Keep `behavior_change=false`.
- Record `allowed_to_enable_default` separately from actual default state.

## Design

- Pull default safety from `complexity_router_default_safety_gate`.
- Include `default_enabled`, `allowed_to_enable_default`, and accidental default enablement count in the shadow evidence.

## Acceptance

- Evidence records `default_enabled=false`.
- Evidence records zero accidental default enablement events.

## Status

Completed in v0.2.82.
