## Problem

Adaptive Template policy has evidence for deep-resolving and shallow-resolving families, and policy-default reliability now has a closure slice. The next risk is no longer whether adaptive should be default, but whether future evidence can quickly reveal family drift, timeout regressions, or override visibility loss.

## Boundary

- In scope: deterministic monitoring snapshot over existing E05 raw evidence.
- In scope: family coverage, effective depth, source, build status, timeout signal, benchmark pass, and override visibility.
- Out of scope: paid reruns, new adaptive heuristics, UI dashboard, or deleting fixed-depth overrides.

## Final Design

`scripts/e05_adaptive_monitoring_snapshot.py` reads selected raw E05 evidence files, extracts adaptive/default arms, builds a compact family/status matrix, records current override options from the latest policy-default run, and emits alerts only for concrete evidence issues such as timeout-like failure, non-published default path, missing override metadata, or missing benchmark pass.

## Acceptance

- Snapshot includes `data_analyzer`, `code_review`, and latest policy-default `data_analyzer` coverage.
- Snapshot reports fixed-depth override options remain visible.
- Snapshot reports no critical alert for the latest policy-default closure.
- Focused tests pass.
