## 1. Goal

Renew worker leases while registered handlers are running.

## 2. Module Boundary

Backend:

- `platform/backend/src/agent_platform/worker_runner.py`

## 3. Implementation Plan

1. Add `renewal_interval_seconds` to `PlatformHarnessWorkerRunner`.
2. Start an async renewal loop after lease claim and before handler dispatch.
3. Renew the task lease until the handler finishes or fails.
4. Cancel the renewal loop before finishing the task.
5. Record `renewal_count` in worker runner metadata.

## 4. Acceptance Criteria

- Existing success/failure/skip behavior remains unchanged. Completed.
- A long-running handler can finish successfully with a short lease. Completed.
- Finished task metadata includes renewal count. Completed.
