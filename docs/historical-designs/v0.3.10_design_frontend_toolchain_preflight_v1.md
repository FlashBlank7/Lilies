## Problem

`node` and `npm` are repeatedly missing from the shell PATH, blocking TypeScript/lint verification. The project needs a deterministic preflight instead of rediscovering this late in every version.

## Boundary

Do not install or vendor Node tooling in this stage. Detect availability, package metadata, and fallback readiness.

## Solution

- Add a Python preflight that checks package files, lockfile, Next config, and executable availability.
- Record tool versions when available.
- Treat missing frontend runtime tools as an explicit fallback condition, not an unexplained failure.

## Acceptance Criteria

- Preflight reports `node`, `npm`, `pnpm`, and `yarn` availability.
- Preflight verifies `package.json`, `package-lock.json`, `next.config.ts`, and `tsconfig.json`.
- Evidence explains whether TypeScript/lint verification can run or which fallback is active.

## Evidence Requirements

- v0.3.10 JSON evidence.
- Focused tests.
