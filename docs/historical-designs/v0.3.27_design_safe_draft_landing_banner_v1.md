## Problem

The recommended safe-draft action redirects to `?safeDraft=1`, but the detail page does not explicitly tell users that no model team was started.

## Boundary

- Read URL state locally.
- Do not call backend APIs because the banner is visible.
- Do not change existing tab behavior.

## Solution

- Detect `safeDraft=1` in the detail page URL.
- Show a compact safe-draft landing banner above existing canvas guidance.
- Explain that the user is viewing an editable safe draft created without model-team startup.

## Acceptance Criteria

- Banner appears only for `safeDraft=1`.
- Banner copy is bilingual.
- Banner uses a stable `data-safe-draft-landing` marker.

## Final State

- Implemented in `platform/frontend/app/applications/[id]/page.tsx` as `safeDraftLanding` URL state.
- Banner appears in the canvas guidance area with `data-safe-draft-landing="active"`.
- Bilingual copy is implemented in `platform/frontend/lib/i18n.ts`.
- Styling is implemented in `platform/frontend/app/globals.css`.
