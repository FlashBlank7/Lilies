## Problem

E08 full sidecar completion is too broad to implement directly. The next step must decompose the remaining boundary into concrete product slices and select the first unblocked implementation slice.

## Boundary

- Do not claim full Platform Harness sidecar completion.
- Do not duplicate the completed E08 tranche: deterministic comparison, editable API, Studio controls, and operator runbook.
- Keep completed/blocked lane exclusions from v0.2.104.
- Select one concrete next slice with verification targets.

## Final Scheme

Represent E08 remaining gaps as scoped candidates:

- allowlist-grade stdio/container egress contract;
- KMS/rotation-grade secret envelope;
- complete handler catalog;
- distributed heartbeat registry;
- long-running sidecar operations runbook beyond policy-controls.

Score each candidate by sidecar-criticality, readiness from existing evidence, product value, testability, and scope risk. Select the highest-scoring concrete implementation slice.

## Acceptance

- Evidence keeps full sidecar completion false.
