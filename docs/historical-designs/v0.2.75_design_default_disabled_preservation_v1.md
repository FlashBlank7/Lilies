## Problem

`allowed_to_enable_default=true` could be misread as actual enablement.

## Boundary

This design preserved status semantics only. It did not change runtime defaults.

## Final Design

- `allowed_to_enable_default=true` means guardrail prerequisites are satisfied.
- `default_enabled=false` means default router behavior is still off.
- Stage report carries live validation as the next step.
