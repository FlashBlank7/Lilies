# design_v0.2.33_e01_complex_paid_ab_v1

## Goal

Run and report a bounded paid/live A/B comparing:

- `planning_mode=required`
- `planning_mode=disabled`

on `LIVE_BUILDER_BENCHMARK_CASE=complex_research_brief`.

## Module Boundary

- In scope:
  - paid/live benchmark evidence under `docs/experiment-status/evidence/`
  - concise DOCX report under `docs/experiment-status/reports/`
  - experiment ledger update in `docs/experiment-status/v0.2_experiment_status.md`
  - stage report and archive files
- Out of scope:
  - declaring E01 fully closed unless evidence supports it
  - productizing planning-mode UI
  - broad Builder prompt rewrite not directly motivated by the complex A/B

## Experiment Design

Run two builds with equal case, timeout, max turns, and benchmark rules:

```bash
LIVE_BUILDER_BENCHMARK_CASE=complex_research_brief \
LIVE_BUILDER_BENCHMARK_PLANNING_MODE=required \
LIVE_BUILDER_BENCHMARK_RESULT_PATH=docs/experiment-status/evidence/experiment_v0.2.33_e01_complex_required_2026_07_09.json \
LIVE_BUILDER_BENCHMARK_MAX_TURNS=36 \
LIVE_BUILDER_BENCHMARK_TIMEOUT_SECONDS=1200 \
.venv/bin/python scripts/live_builder_benchmark_suite.py
```

```bash
LIVE_BUILDER_BENCHMARK_CASE=complex_research_brief \
LIVE_BUILDER_BENCHMARK_PLANNING_MODE=disabled \
LIVE_BUILDER_BENCHMARK_RESULT_PATH=docs/experiment-status/evidence/experiment_v0.2.33_e01_complex_disabled_2026_07_09.json \
LIVE_BUILDER_BENCHMARK_MAX_TURNS=36 \
LIVE_BUILDER_BENCHMARK_TIMEOUT_SECONDS=1200 \
.venv/bin/python scripts/live_builder_benchmark_suite.py
```

## Metrics

Compare:

- build status
- benchmark pass/fail
- benchmark score and pass rate
- missing node/harness types
- draft node/edge/test counts
- model/tool calls
- build_plan call count
- runtime duration

## Acceptance Criteria

- Both runs either complete or fail with clear evidence files.
- A summary JSON compares both arms.
- A DOCX report includes `背景`, `实验设计`, `结果结论`, `图片或截图`, and `证据链`.
- If the experiment result triggers engineering change, that change must be narrow, evidenced, and marked as applied in the ledger/report.
- If results are inconclusive, E01 remains open with a precise next action.
