# design_template_rag_reuse_marketplace

## 1. Goal

把生成后的可复用 BlockFlow 沉淀为 Template，并通过检索、复用深度和模板市场展示形成自动智能体创建 loop。

Status: implemented as v1 on 2026-07-08; embedding RAG not implemented.

## 2. Module Boundary

候选模块：

- `template_store.py`
- `builder.py`
- `workflow_storage.py`
- future frontend marketplace view

## 3. Data Flow

已验证 BlockFlow -> Template metadata -> embedding / keyword index -> Builder `template_suggestions` -> shallow/deep reuse -> 修改和测试 -> 新 Template 候选。

## 4. Implementation Plan

1. 已定义复用深度：none、shallow、deep。
2. 已在 Builder `template_suggestions` 和 API suggestions 中接入复用深度。
3. 先用 metadata/keyword 做检索，后续再接 embedding RAG。
4. 模板必须保留测试门禁和来源证据。
5. 模板市场只展示已验证 Template。

## 5. Acceptance Criteria

- Builder 能解释为什么选择某个 Template。
- Template 展开后仍可编辑、测试、发布。
- E05 能验证复用深度收益。
