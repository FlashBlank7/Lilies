- Source task: `Preserve default-disabled status`

## Problem

Selecting a path toward productization must not accidentally turn into default router enablement.

## Boundary

- Keep `default_enabled=false`.
- Record default enablement as explicitly deferred.
- Require frontend verification before default enablement review.

## Design

- Include default safety status in the decision evidence.
- Select only a no-runtime-change next path.

## Acceptance

- Evidence records `default_enabled=false`.
- Selected next path does not change runtime behavior.
