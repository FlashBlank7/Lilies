## Problem

Empty-state copy tells users to clear search or switch filters, but the UI does not provide direct recovery actions.

## Boundary

- Controls may only update local state and URL state.
- Do not call any backend write endpoints.
- Preserve existing filter/search/sort controls.

## Solution

- Add a clear-search button when search is active.
- Add a reset-view button when filter/search/sort differs from defaults.
- Reuse the safe URL-state writer from v0.3.21.

## Acceptance Criteria

- Clear search removes `q` and keeps filter/sort.
- Reset view returns to all/readiness/empty search and removes list URL query values.
- Buttons are disabled/hidden when not applicable.
