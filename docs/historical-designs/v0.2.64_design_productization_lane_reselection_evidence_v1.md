## Problem

After v0.2.60-v0.2.63 closed the adaptive monitoring lane, the project needed a fresh source-linked selection between the two remaining productization candidates: E08 extended controls and complexity-router rollout.

## Boundary

This design selected the next lane. It did not implement E08 controls or enable the complexity router.

## Final Design

- `scripts/v02_64_productization_lane_reselection.py` scores E08 extended controls and complexity-router rollout.
- The formula is `evidence + readiness + product_value + next_slice_specificity - default_risk_blocker - governance_blocker`.
- Selection evidence is emitted as JSON and markdown.
- E08 wins because its first comparison is closed, runnable, and a bounded controls surface can improve operator governance without risky default behavior.
- Complexity-router remains deferred because its ledger records `router_ready_for_default=false` and requires guardrails plus rollout design.

## Acceptance

- The script deterministically selects one next implementation lane.
- Both source paths are recorded.
- The output names a next version and first design target.
- Tests pass.
