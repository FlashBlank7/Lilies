## Problem

Saving a safe draft from a scenario currently produces a generic `customer_request` Start input. For the Japanese learning scenario, the user expects a field like "关注的日语主题" and visible workflow steps.

## Boundary

- Only specialize the safe draft skeleton when the requirement clearly matches the Japanese spoken-expression scenario.
- Keep the no-model safe draft boundary.
- Do not call external video sites or model APIs.

## Proposed Solution

- Add scenario detection for Japanese spoken-expression requirements.
- Seed a scenario-specific safe draft with:
  - Start input `topic`, label `关注的日语主题`.
  - Step placeholders for collecting comment context, extracting spoken expressions, and generating a daily summary.
  - A structural acceptance case with a sample topic.

## Acceptance Criteria

- Safe draft for the Japanese scenario has a topic input.
- Draft step titles match the scenario.
- No model/build/run API is called during safe draft creation beyond existing draft mutations.

## Final State

- Completed in `v0.3.49`.
- Added Japanese-learning requirement detection and a no-model scenario skeleton.
- The skeleton creates topic input, comment clue collection, spoken expression extraction, final daily summary, and a structural acceptance test with sample topic `校园生活`.
