## Problem

Users can select a scenario and edit the prompt, but they do not get local feedback about whether the requirement is specific enough before saving a draft or starting the builder team.

## Boundary

- Use local heuristics only.
- Do not call models or backend endpoints.
- Do not block editing.

## Solution

- Add a compact readiness panel inside the create card.
- Score four signals: customer/role, outcome, acceptance, and detail length.
- Show ready/needs-detail state.

## Acceptance Criteria

- Summary updates from current requirement text.
- No model call is introduced.
- Copy is bilingual.
