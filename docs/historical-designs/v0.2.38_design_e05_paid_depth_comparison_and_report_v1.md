## 3. Data Flow / Control Flow

1. Run deterministic tests for the runner.
2. Execute paid/live E05 runner with explicit budget:
   - three arms
   - bounded `max_turns`
   - bounded `max_repair_cycles`
   - configured provider/model captured from `/health`
3. Inspect JSON evidence and summarize per-arm outcomes.
4. Generate DOCX report with:
   - 背景
   - 实验设计
   - 结果结论
   - 图片或截图
   - 证据链
   - 工程应用状态
5. Update experiment ledger:
   - E05 status changes from artifact review only to live comparison completed or partially blocked.
   - Application marker remains conservative unless the experiment result directly drives an engineering change.
6. Run full regression tests.
7. Create stage report, historical designs, workingon archive, clear active workspaces, and commit.
