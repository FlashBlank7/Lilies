## Problem

The detail Build tab explains action state, but users still have to map that explanation to the right next step.

## Boundary

- Local state only.
- No direct build call.
- Do not replace the existing start-team button.

## Solution

- Add `recommendedDetailBuildAction`.
- Focus the requirement textarea for edit states.
- Focus the guarded build button for arm/confirm states.
- Disable the affordance while a build is busy.

## Acceptance Criteria

- Recommended action has deterministic targets for all detail build states.
- Edit states focus requirement input.
- Arm/confirm states only focus the guarded button.

## Final State

- Implemented in `platform/frontend/app/applications/[id]/page.tsx` as `recommendedDetailBuildAction` and `runDetailBuildRecommendedAction`.
- Added `data-detail-build-recommended-action` and `data-detail-build-recommended-target`.
- Edit states focus the Build tab requirement textarea; arm/confirm states focus the guarded build button only.
- Verification is recorded by `scripts/v03_31_detail_build_recommended_action.py` and `tests/test_v03_31_detail_build_recommended_action.py`.
