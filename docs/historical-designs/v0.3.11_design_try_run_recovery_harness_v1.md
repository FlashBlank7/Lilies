## Problem

The project needs evidence that an operator-like user can run a safe draft without starting the builder team, and can see recovery guidance when things are not ready.

## Boundary

Use a local safe Start-to-Answer skeleton. Do not call `/builds`.

## Solution

- Add a v0.3.11 harness that creates a smoke app, seeds a safe draft, runs it with sample input, polls the run result, and cleans it.
- Preserve i18n completeness via v0.3.10 regression.

## Acceptance Criteria

- Live operator persona run succeeds or records a clear non-build run result.
- Endpoint ledger excludes `/builds`.
- Smoke artifacts are cleaned.
