## Product Surface

- GET `/api/v1/templates/adaptive-monitoring` now includes `last_refresh`, recent `history`, `history_count`, and `history_path`.
- POST `/api/v1/templates/adaptive-monitoring/refresh` records a manual refresh event in runtime `data_dir`.
- Studio adaptive monitoring card has a record-refresh button and freshness fields.

## Key Result

Adaptive monitoring is no longer only a static read surface. Operators can record a deterministic refresh over current evidence and see when the surface was last refreshed, without launching paid/live model work.
