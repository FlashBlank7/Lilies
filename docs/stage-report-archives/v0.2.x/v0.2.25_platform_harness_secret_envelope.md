# v0.2.25 Platform Harness Secret Envelope

## 1. Stage Goal

Harden Platform Harness secret references by storing newly saved secrets as authenticated local envelopes instead of plaintext in `platform_secrets.value`.

This stage does not complete KMS or external secret-manager integration. It closes the immediate local plaintext persistence gap from `v0.2.21` while preserving runtime injection and legacy plaintext compatibility.

## 3. Completed Items

- Added `platform_harness_secret_envelope_key` setting.
- Passed an explicit envelope key, or API token fallback, into `PlatformHarness`.
- Added versioned `secret-envelope:v1:` storage format without a schema migration.
- Added authenticated envelope helpers using standard-library PBKDF2-HMAC-SHA256, HMAC-SHA256 keystream, and HMAC authentication.
- Updated `save_secret()` to persist encrypted envelope text when an envelope key is configured.
- Updated secret reference resolution to decrypt encrypted rows at injection boundary.
- Preserved legacy plaintext row compatibility.
- Added public secret metadata: `storage_mode` and `encrypted`.
- Added focused regression tests for raw storage non-plaintext, decrypted injection, and legacy plaintext compatibility.
