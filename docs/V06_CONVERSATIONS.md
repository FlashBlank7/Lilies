# v0.6 独立项目会话

项目“对话”页可以新建、重命名和切换会话。会话归当前账号所有；同一个项目的成员各有自己的会话列表。项目负责人也不会自动读取协作者的新会话。

每个会话分别保存用户消息、模型历史、操作记录、活动状态和运行句柄。切换会话不停止后台工作；“停止”仅停止当前会话及其发起并跟踪的运行。停止后可在原会话继续，服务重启保留历史并将未完成轮次标记为中断。关联的智能体任务继续时恢复原会话，不进入项目的其他会话。

项目资料、模型连接、模型版本、工作流、Skill、进展和保存的运行结果仍然共享。对话本身不自动合并；主动保存到项目文件、进展或任务结果的内容属于共享资源。修改主模型连接前需要停止本项目的活动会话，随后各会话保留自己的历史并使用新连接。

未发送输入和阅读位置按账号、项目、会话保存在当前浏览器标签页；它们不是服务器消息，也不自动跨设备同步。已发送历史、会话名称和任务保存在服务器。页面刷新恢复当前会话；切换时不会把旧会话的延迟发送回调应用到新输入。

旧的单一项目会话保留为“历史项目会话”，由项目负责人及管理员访问。协作者使用新建会话；旧兼容接口不向协作者暴露历史记录。没有删除或重写旧模型会话文件。

## 接口与存储

- `GET/POST /api/v1/projects/{project_id}/conversations`：列出当前账号会话、创建会话。
- `GET/PATCH /api/v1/projects/{project_id}/conversations/{conversation_id}`：分页读取消息、重命名。
- 同一路径下的 `/messages`、`/stop`、`/metrics`：发送或继续、停止、查看用量。
- `kind=tools` 和 `kind=activity`：按需读取当前会话操作记录；分页游标不能跨会话使用。

新增会话元数据表以及项目任务的可空语义会话标识（旧任务默认为空串）。模型历史与状态写入独立会话目录；运行中的异步任务继承会话标识，项目工作目录与资源标识保持原值。

## 验证范围

自动测试覆盖两个账号同项目的会话权限、旧会话保留、真实平台模型循环的历史隔离与重连、同时执行时停止互不干扰、服务初始化恢复、关联任务继续回到原会话。模型响应使用替身供应商，没有外部模型调用。

前端测试及生产页面验证新建、重命名、各自草稿、切换和刷新恢复；测试还覆盖延迟发送回调与停止目标。尚未将第二台设备和真实模型长任务的验收计为完成。
