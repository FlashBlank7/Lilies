# 官方智能体与内部复用

员工界面统一称为“官方智能体”。具体接入实现只展示在管理员设置中。现有 API 项目、工作流模型连接与历史结果保持独立。

## 配置和使用

1. 管理员打开全局导航的“官方智能体”。可以连接服务器已有的订阅登录，也可以打开浏览器登录或设备码登录；不收集账号密码。
2. 刷新模型和额度目录，选择实际支持的模型及思考强度。默认配置为 `gpt-5.6-luna / max`；不存在时显示具体原因，绝不降级或自动换模型。
3. 初始并发 1、个人额度保留 50%、每任务 32000 token、模型执行时限 600 秒。等待平台计算时不占用新的模型调度名额。token 根据服务返回的实际用量控制，正在生成的响应可能超过阈值。
4. 管理员在项目对话的“智能体来源”中明确允许完整智能体能力、授权官方智能体，并选择任务与工作流生成的来源。新旧项目默认均不授权。
5. 员工进入自己的会话，选取项目资料后发送消息。排队原因、运行和等待计算状态会显示在对话中。停止只影响此请求及其关联计算。
6. “创建工作流”也可以使用官方智能体。生成请求立即返回任务编号，刷新可接续查看、可以停止；只返回工作流结构，不开放业务工具。API 生成路径保持兼容。人工同时修改画布时仍以修订号检查冲突。

工作流中的 `llm`、视觉和 Embedding 继续使用原始 API。官方智能体不伪装成这些模型积木的服务商；配置业务 API 不会替换官方智能体的员工会话。

账号凭据放在平台数据目录中的私有服务目录。每个会话独立存储 thread，只有服务登录材料被引用；不会读取个人 Codex 配置、历史、记忆、插件或工作目录。子进程不继承 `OPENAI_API_KEY` 或 `OPENAI_BASE_URL`，使用订阅认证并拒绝 API Key 模式。模型出口仍遵守服务端 `MODEL_EGRESS_ENABLED`；自动测试保持关闭。管理员的“启用”开关不越过这个部署设置。

## 排队、恢复与额度

SQLite 保存请求队列。按员工轮换，同一会话的模型请求串行。客户端重试保留请求标识，重复请求不重复启动。训练由已有项目计算任务执行，不建立第二套训练运行时。

任何官方额度窗口达到保留线、服务返回不允许继续使用、账号失效或额度未知时，新请求保持等待。已开始的任务不因保留线突然停止。管理员可以调整保留比例和并发；模型/程序变化需要先停止活动请求。不会自动购买额度、兑换重置权益或换计费来源。额度保留是派发阈值，无法锁住其他客户端的消耗。

服务重启后继续尚未开始的请求；已经开始的请求标记中断，人工继续原会话。不会自动重复提交训练。工作流生成的请求和结果也保存在服务端；浏览器保存待查看的任务编号，重开原页面继续查询。

## 保存、共享与再次调用

- 对话结果的“保存方法”允许编辑并保存项目 Skill，不调用模型。项目智能体可以按用途发现、读取这些说明。
- 项目空间的“内部共享方法与流程”允许主动分享到自己可访问的指定项目；其他项目不可见。接收方加入独立副本，重复点击不会重复安装。
- 工作流分享包含关联子流程、节点内代码和来源修订号。子流程调用重新映射；实际模型、数据和凭据绑定清空，变量引用保留。不会打包原始文件、模型包、连接或聊天。
- 外部代码文件和 Skill 引用资料不自动复制。引用这些资料的定义需在接收项目补齐；分享前可预览精确内容。用户自行写入代码或提示词的私人文本仍属于所选定义，应在分享前移除。
- 更新分享不覆盖已加入的副本。复用原流程预测、编辑报告等能力沿用现有运行时；本轮没有重新制作已验证的官方机器学习流程。

## 使用统计

管理员页分开展示账号额度、平台任务与功能统计。记录对话、上传、生成、编辑、训练、预测、下载请求、方法保存及复用。工具调用以独立发起方和根请求关联，不能计成更多员工任务。结果可标记“有用／需要修改”。

统计只保存标识、功能、状态、时长和已报告 token，不保存消息、文件或凭据。统计写入失败不使业务失败。明细默认保留 30 天、日汇总 180 天。从本功能启用后开始统计；未采集的历史不补估。下载计数表示服务器收到的下载请求，不能证明用户已保存文件。账号在其他客户端的用量不归入平台任务。

## 验证边界

账号登录、模型目录、额度通过真实服务器只读查询核对。会话、工具、队列、生成和授权的自动测试使用协议替身，模型出口关闭。真实推理和完整员工训练闭环必须在账号额度满足保留线、模型出口明确启用时另行核验，不能用替身结果声称已通过。

本实现使用 [Codex App Server 官方协议](https://learn.chatgpt.com/docs/app-server)，接入账号、模型、额度与 thread/turn 接口。CLI 版本在连接时记录；变化后要求重新连接核对。技术连通不代表个人订阅的多人服务套餐适用范围已经获得确认；原计划中的这一边界仍保留。
