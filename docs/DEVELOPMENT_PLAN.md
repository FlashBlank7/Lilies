## 新增必交付能力：登录系统与项目权限

开放注册；用户名密码；普通用户自行配置项目模型；项目按成员共享。新增会话、账号页面、成员管理和统一接口权限，管理员本机初始化，兼容保留旧数据。实现和验证范围见 [登录说明](V06_AUTH.md)。

登录系统属于 9 月 27 日可独立试用原型范围。用户从登录进入自己的项目，再完成上传、对话、训练、工作流编辑、运行和下载。它不增加工作流生成的需求确认、计划审批或资源就绪门槛。

首版范围：注册、登录、退出、修改密码；管理员初始化、账号禁用及密码重置；项目负责人和协作者；页面、接口、下载及运行事件使用一致的访问权限。原有项目、资料、模型和报告保留，由管理员指定旧项目负责人。短信、邮箱验证及企业 SSO 不作为本阶段前置条件。

- [x] 注册登录、账号管理、项目成员、项目画布与运行表单联调及回归。
- [x] 旧使用链接进入所属项目的运行表单，按成员权限运行当前草稿。
- [x] 可信代理按访客 IP 传递注册/登录限速地址，伪造头拒绝；实际 Nginx → 前端 → 后端链验证通过。部署配置与 NAT 限制见登录说明。
- [x] 验证旧项目迁移、失效会话和实时连接权限撤销；两个账号页面协作。
- [ ] 多设备真实使用验收。

登录交付验收：两个普通账号默认无法访问对方项目；加入成员后可协作，移除后后续请求失去权限；退出、密码重置和禁用按约定使会话失效；第二台设备登录后完成主要业务操作。登录会话与智能体对话分别验收，多个登录设备不等于多个独立智能体对话已经完成。
