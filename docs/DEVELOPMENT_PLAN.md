# v0.6 开发计划

目标：9 月 27 日机器学习主路径可独立试用。产品为自主智能体、按需 Skill 和可管理工作流；生成与资源就绪解耦。工作流搭建暂由 Codex 代劳，平台能力仍需完整实现和验收。

当前交付：[v0.6 原型交付说明](RELEASE-v0.6-prototype.md)。9 月 21 日用户确认继续交付，系统文件窗口保留为验证限制，不再作为整个平台交付阻塞。

9月28日补充[用户意见反馈](USER_FEEDBACK.md)：全局主动建议与使用中的关联反馈、管理员站内回复、处理状态及未读提醒已实现；员工和管理员浏览器闭环通过。提交反馈本身不调用模型，后续实际员工意见仍需在试用中收集。

9月28日增加[使用轨迹驱动改进](USAGE_IMPROVEMENT.md)：后台自动整理运行与接口线索；管理员可限定项目开启官方智能体自动处理，复用现有会话、权限、停止及用量机制。离线智能体替身已通过自动派发、独立修复副本及两组真实计算；主平台自动整理启用，自动模型处理待管理员选择项目开启。平台源码的无人值守修改和发布尚未实现。

同日补齐处理结果：按需查看本人处理会话的实际状态、回复、失败原因及关联任务，可停止、进入原会话继续沟通、标为已处理或重新打开。真实官方智能体在自编缺陷案例中创建独立副本并完成两组输入计算，保留原流程；实测修复了模型恢复文件缺失后无法接续的问题，并分开官方智能体与原始 API 的出口配置。此小案例服务记录用量286,861 token、模型执行约90秒，尚不适合据此宣称低成本规模化自动维护；后续重点减少工具尝试和上下文开销，不反复追加同一案例的付费测试。

后续减耗已完成两个小阶段：项目智能体结构验证不再因缺少验收测试或资源尚未绑定而无效；完整积木说明与通用schema拆开按需读取，旧完整返回保留。相同自编缺陷的离线工具回放仍能保存副本、通过结构验证并完成两组计算；两份说明加一次图schema共8,244字节，原来为18,365字节。另修正工具组介绍导致无关工具命中的问题，默认使用简短用途并按需读取详细帮助，全部17个工具及完整参数保留，调用无需先查手册。受影响后端97项通过、4项按原条件跳过；两个阶段均未新增真实模型调用，实际调用次数、token和耗时下降幅度尚未复测。详见[使用改进的减耗记录](USAGE_IMPROVEMENT.md)。

处理接续补充：首次启动失败后，可以直接进入保留的项目会话；返回使用改进页按实际状态显示停止、继续与回复。重试不重复发送初始任务，连接失败后立即显示保留入口。独立模拟管理员的桌面闭环通过，使用离线官方协议替身，未新增真实模型调用。

多工作流版本识别已补齐：比较入口及引用的子流程，循环内部同样识别；动态目标保守覆盖项目可调用成员。子流程已改的旧失败不自动派发，不同子版本的成功次数分开；保留原线索状态、会话和实际自动尝试次数。真实运行时与迁移行为测试通过，未新增模型调用。模型绑定、外部文件及环境变化不在此次版本核对范围内；真实模型减耗幅度、实际员工反馈及平台源码无人值守修改发布仍待后续。

对话路径补充：请求已接受但随后失败也会进入使用改进，官方对话/生成沿用已有记录，API对话从更新起记录终态。页面展示重复失败、之后的完成次数及独立采样范围，不读取私聊、不自动判定修复、不自动重试连接；维护会话排除。桌面与模拟窄屏、后端会话回归及前端测试构建通过，模型调用0。

## 新增必交付能力：登录系统与项目权限

开放注册；用户名密码；普通用户自行配置项目模型；项目按成员共享。新增会话、账号页面、成员管理和统一接口权限，管理员本机初始化，兼容保留旧数据。实现和验证范围见 [登录说明](V06_AUTH.md)。

登录系统属于 9 月 27 日可独立试用原型范围。用户从登录进入自己的项目，再完成上传、对话、训练、工作流编辑、运行和下载。它不增加工作流生成的需求确认、计划审批或资源就绪门槛。

首版范围：注册、登录、退出、修改密码；管理员初始化、账号禁用及密码重置；项目负责人和协作者；页面、接口、下载及运行事件使用一致的访问权限。原有项目、资料、模型和报告保留，由管理员指定旧项目负责人。短信、邮箱验证及企业 SSO 不作为本阶段前置条件。

- [x] 注册登录、账号管理、项目成员、项目画布与运行表单联调及回归。
- [x] 旧使用链接进入所属项目的运行表单，按成员权限运行当前草稿。
- [x] 可信代理按访客 IP 传递注册/登录限速地址，伪造头拒绝；实际 Nginx → 前端 → 后端链验证通过。部署配置与 NAT 限制见登录说明。
- [x] 验证旧项目迁移、失效会话和实时连接权限撤销；两个账号页面协作。
- [x] 按用户要求改用模拟设备验收：独立容器经局域网入口验证两个账号、成员权限、上传、运行与下载；浏览器实际复测 HTTP 局域网页面，见 [安装说明](V06_INSTALL.md)。不将模拟称为物理设备或路由器验证。

登录交付验收：两个普通账号默认无法访问对方项目；加入成员后可协作，移除后后续请求失去权限；退出、密码重置和禁用按约定使会话失效；按用户要求通过独立容器模拟另一台设备，并用局域网 HTTP 浏览器验证主要页面操作。登录会话与智能体对话分别验收，多个登录设备不等于多个独立智能体对话已经完成。
