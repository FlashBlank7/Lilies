# 预测与实测反馈对照

2026-09-25。把已经保存的预测与后来取得的实测值、人工复核标签关联，解释整体及不同批次的差异。员工不需要重新训练，也不需要选择算法。

在项目空间的「公共工作流市场」加入同名流程，获得独立可编辑副本及配套 Skill。也可以在「从示例创建」选择同名项目；示例是自编资料，创建不会启动计算。通过对话调用时仍需要项目智能体连接，流程本身只有开始、两个代码步骤和结果节点，不调用大模型或预测服务。

## 员工怎么用

1. 选择项目里的预测文件。已有平台预测结果的 `result.project_path` 可以直接传入 `source_path`，也可在文件下拉框选择。
2. 实测在另一份文件时选择实测表；已经合并在预测表里时留空。两表按同名标识列对应，多个字段用逗号分隔，例如「样本编号,版本」。不根据行号猜测对应关系。
3. 下拉选择「数值预测」或「类别判断」，填写预测及实测列名。可按预测表中的批次、设备等字段分组；可以不填基线和业务容差。
4. 查看有多少记录能够评价、哪些没有对应或有缺值，再看指标和分组结果。下载逐条对照、分组、未匹配实测及说明。
5. 换资料、补齐字段或修改分组后重新运行；旧报告保留。只改采纳规则使用规则重算流程，需要改模型时再提出训练任务，没有统一前置审批。

建议问题：「把这些预测和实际检测结果对照一下，告诉我哪些批次偏差比较大，哪些还不能评价，不重新训练。」Skill 同时说明何时使用分析、预测或规则重算流程，不要求员工记内部编号。

## 怎样比较

| 情况 | 处理及解释 |
| --- | --- |
| 记录乱序 | 按一个或多个明确标识关联，结果保持预测表顺序 |
| 重复或空标识 | 指出文件和记录号；员工选择版本或补充组合标识，不自动去重 |
| 无匹配实测、预测/实测缺失或数值非法 | 原行保留并说明原因，不进入指标；实测中没有预测的行单独导出 |
| 数值结果 | 误差为预测减实测，正值表示偏高；MAE表示通常差多少，RMSE更重视大误差，单位与实测一致 |
| 实测为0、常量或没有有效行 | 0是有效数值；MAPE排除0并单列分母，近0可能失真；常量实测的R²不定义；没有有效行时指标为空，不显示完美成绩 |
| 类别结果 | 精确比较去除首尾空白的字符串；真实或预测中出现的所有类别都进入宏平均，展示类别数量与混淆计数；不猜测1与1.0是否同义 |
| 可选业务容差 | 留空不判合格，0要求完全相等；比例只针对有效行，不代表产品放行。类别任务填写数值容差会提示清空 |
| 可选已有基线 | 只在模型、基线和实测均有效的同一组行上比较，并显示共同样本数；类别集合取双方预测及实测并集，使用相同宏平均口径 |
| 分组 | 同时显示每组总数和有效数；类别任务使用整体类别集合，缺类不改变分母；不把小样本差异解释为原因或稳定性证明 |

每次运行保存两份输入的路径、内容哈希、Excel工作表及固定快照；下游评价使用该快照。之后修改源文件不会改变原报告。中间快照内容被修改时明确失败，重新读取资料即可继续新运行。所有结果写入独立目录，原始资料不变。

逐条CSV保留预测原字段及 `eval_` 结果字段；拒绝覆盖已有同前缀字段。报告提供预测与实测预览、普通语言说明、未匹配原因和下一步建议。附加下载包含分组CSV、未匹配实测CSV、汇总JSON；类别任务另有每类指标与混淆计数CSV。指标缺分母时不定义，类别宏平均中的不可定义精确率/召回率按0计入并在说明中标明。

首版支持UTF-8 CSV、TSV和XLSX（运行环境需openpyxl），单文件10 MB、10万行。多工作表必须明确选择；类别超过100种提示检查任务或字段。分组元数据如不在预测结果中，可先用现有表格关联流程整理。本流程不进行时序因果判断、概率校准、标签生成或现场回写。

## 来源与实际验证

- 私有工业项目有220条历史预测及实测记录，分属22个工单，组合标识没有重复。平台代码步骤实际执行，整体MAE、RMSE、偏差及全部分组结果与独立Decimal/逐组计算一致，运行观测约1.63秒。
- 原历史表的误差定义为实测减预测；新流程明确采用预测减实测，已核对符号，绝对误差一致。原训练/测试来源尚不能确定，本次只证明关联和算术，不宣称泛化准确率或生产效果。
- 原反馈代码还包括空间权重调整及切割重算；它们是后续候选方法。没有直接把加权更新称为已经证明的贝叶斯推断，也没有把领域切割规则搬作通用默认。
- 已有平台模型产生的20条预测，通过项目结果路径直接交给新流程，配合明确标注的构造复核标签完成评价；没有新增训练，模型及原预测结果不变。这验证复用接口，不评价该模型生产效果。
- 后端行为测试覆盖数值/类别、零值与缺失、组合标识、重复、工作表、基线共同样本、固定指标例、失败修复及输入快照隔离。平台测试验证示例安装、运行、下载、Skill及没有训练任务。
- 模拟员工从浏览器创建项目、运行、下载CSV；换实测后有效数由3变4且示例误差变为0。类别任务错误容差得到明确提示，清空后重试；桌面及390×844视口分别操作。自编样例不等于公司效果验收，模拟员工不等于真实员工反馈。
