# v0.6 机器学习原型试用

独立任务、工作流草稿和项目资源分别保存。可以先训练，也可以先画流程；生成或保存草稿不会自动执行业务。

## 运行准备

按 [README](../README.md) 启动后端、前端和本机 Docker。保留项目使用的建模镜像及数据目录。项目对话与生成工作流需要在“设置”配置原始模型 API；手工搭建和 CPU 训练不需要模型服务凭证。完整智能体积木由项目权限单独控制。

## 页面主路径

登录后在项目“对话”页点击“新建会话”即可开始。不同会话各自保存历史，可以切换和重命名；同项目的模型、文件和工作流仍共享。切换不会停止后台任务，停止或继续针对当前会话。详见 [独立会话说明](V06_CONVERSATIONS.md)。

1. 新建项目，在“模型”导入 CSV/TSV，选择预测目标列。也可展开“粘贴表格数据”，填写首行为字段名的文本，再导入。无标签预测数据不选目标列。
2. 在“可调用模型”填写稳定名称（如 `prediction`），点击“创建预测工作流”。此时可以还没有任何训练产物；草稿会保留，运行时才提示未绑定的模型及具体节点。
3. 在“训练模型”选择数据、任务类型和算法，点击“开始独立训练”。没有训练工作流也能执行，运行记录显示真实状态；可以停止并继续原任务。
4. 训练结束后选择训练记录和具体模型版本，点击“绑定模型版本”。预处理代码和运行环境随模型版本使用。
5. 回到原预测工作流，选择新的无标签数据集并运行。结果页面下载预测 CSV；模型页可查看指标、训练笔记及下载模型。
6. 可以通过对话反馈结果、要求比较新候选，或要求发现并调用项目中已有的工作流。项目说明在“资料与知识”编辑，智能体按需读取正文和引用资料。

“生成工作流”可以随时使用，一次模型响应直接保存图。输入一句需求即可，也可以在工作流页修改当前图。默认使用常用积木；生成选项可启用高级积木，项目权限仍有效。模型没有返回合法配置时显示具体错误，不自动反复付费重试。

如果只需要预测，在模型页选择无标签数据，点击“直接预测”。项目智能体也可用 `project_models(action="predict", model_ref="...", dataset_id="...")` 调用同一服务；两者均不需要工作流。独立训练完成后暂停研究计算计时，查看结果和编辑草稿不消耗训练预算。

## 编辑与运行语义

- 人工和 AI 编辑同一份草稿；保存检查结构、引用和能力权限，运行时检查必需输入与资源。
- AI 修改后可撤销本次修改；切换到运行页再返回仍保留撤销入口。如期间有人保存了新修改，会提示版本冲突并保留已保存内容。刷新整个页面后可查看既有修订记录，当前快捷撤销不跨浏览器刷新保存。
- **再次运行**使用当前草稿和当前资源绑定，创建新运行。
- **继续原运行**保留原工作流和模型版本，使用已经有效保存的执行进度。已经失败的节点会重新执行；未完成训练的试验继续由已有建模内核处理。
- 重新绑定模型不会修改旧结果；旧环境或产物缺失时明确失败，不自动使用替代模型。
- Python 积木定义 `main(inputs)`，输入字段可从上游选择，返回 JSON 可表示的数据。`print` 内容保存在日志；大型结果写到项目 `results/`，返回文件路径。代码和对话共用 Docker 执行能力，不开放网络或项目凭证。

## 范围

当前主路径是本机 CPU/Docker 表格训练、已有时序建模能力及模型复用。原型已用构造数据及 UCI Wine Quality 公开真实数据验证主要使用链，具体结果和未通过项见 [真实数据记录](V06_REAL_ML.md)，不代表客户模型效果或工业业务已验收。语义 RAG 已支持解析、切分、独立 Embedding、索引版本、检索和引用问答；页面操作及真实公开 PDF 的验证范围见 [知识库说明](V06_KNOWLEDGE.md)。

浏览器自动化的本地文件选择仍可能返回 `Not allowed`。该错误发生在自动化文件选择接口，不是已确认的平台上传故障。文件选择组件模拟、页面粘贴导入和真实 multipart 上传保存下载均已验证；原生系统窗口作为验证限制保留，不再阻塞本阶段原型交付。
