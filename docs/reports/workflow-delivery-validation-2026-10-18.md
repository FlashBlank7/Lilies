# 工作流交付入口与失败恢复：修复验证摘要

日期：2026-10-18。开发分支：`codex/workflow-delivery-usability-20261018`，基线：`116ed1af36c9d8c3a2581504359997dff5a654b3`（PR #3）。本摘要供代码审阅使用；没有合并、发布或替换员工服务构建。

## 本批代码的行为变化

- 开始节点保存输入显示名称和填写说明；项目概览和运行表单读取当前草稿。省略 `required` 时与执行端一致，默认必填；显式可选仍可选。
- 选表默认展示上传资料，可主动展开历史结果和其他文件，保留当前选择。
- 当前任务直接提供完整报告、结果表、模型包和文件清单入口，复用现有阅读器与鉴权下载。报告路径来自该任务输出，不从项目的最新文件猜测。
- 新尝试开始即清除旧任务的当前结果，包括输入校验失败、创建请求等待和被拒；重试保留已选输入。执行失败不恢复旧报告。
- 裸 `AssertionError` 显示可读失败摘要，完整错误详情保留。

单处规则修改同时在私有项目副本中修复：补充分析复用上游异常标记，报告和下载阈值表读取本次实际方法及边界，消除写死的 IQR 说明。**这部分是客户工作流迁移，不是本 PR 内的通用平台源码改动；合并本 PR 不会自动修改客户项目。** 迁移脚本、六项流程行为测试和原始项目材料留在私有验证目录，未加入公共仓库。没有新增规则引擎或其他功能。
