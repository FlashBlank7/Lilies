# 示例项目使用说明与验证记录

从「所有项目 → 从示例创建」选择一个场景，查看准备条件后创建自己的副本。资料、工作流、项目 Skill 和默认输入一起加入新项目。创建本身不运行计算、不调用模型；其他员工的副本和后续模板更新都不会覆盖你的修改。

推荐从会议纪要、周报、费用整理或数据体检开始。一次性问题可以直接通过对话处理，重复任务可以调用已有工作流，不要求所有问题先生成流程。

## 如何使用

1. 在示例目录按日常办公、数据处理、机器学习、知识问答或流程搭建筛选。
2. 创建副本后，在项目顶部查看「从这里开始」。点「准备这条消息」会保留已有草稿并追加建议问题，不会自动发送；无会话时先新建会话。
3. 展开「操作步骤、工作流与修改练习」，可查看资料、编辑流程或进入运行参数表单。代码类示例可以直接运行；通过对话使用还需要项目智能体连接。
4. 缺少大模型、Embedding、知识索引或训练环境时，按准备条件配置。完整智能体能力不会随示例自动授权；业务 LLM 节点使用原始模型连接。
5. 在运行记录查看真实结果、步骤输入输出和下载。更换第二份资料或修改参数后重新运行，旧结果保留。

首次注册会自动进入强引导；顶部「使用教程」可重新打开。示例创建弹窗和教程卡片各有独立显示区域，支持桌面与模拟手机尺寸。跳过教程不会改变项目内容。

## 测试与耗时

- 新增示例测试 **28 项通过**，包含 20 项的运行路径、员工账号隔离、重复/并发创建、失败回滚重试、换输入、模型版本及历史结果保留。
- 实际 Docker 镜像：`lilies-modeling:20260922-feature-tables`；每次训练最多两个候选、180 秒总预算、单候选 60 秒。测试套件共 154.52 秒；各机器学习测试约 14–24 秒，包含创建及多次操作，不等同单次训练耗时。
- 受影响后端回归：51 项通过、9 项因未启用真实计算检查而跳过；真实计算已由上述单独测试覆盖。
- 前端全量：186 项通过；生产构建含类型检查通过。
- 浏览器使用模拟员工账号验证注册强引导、目录、独立创建、资料选择、画布打开、消息草稿保留、直接运行、换资料、旧报告保留及实际 CSV 下载事件。桌面与 390×844 视口分别检查；不等同真实员工反馈或跨设备网络验收。
