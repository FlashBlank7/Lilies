# 当前版本的机器学习能力升级

目标来自用户：彻底进化机器学习的能力。工作覆盖从企业数据到可复用预测流程的完整路径，不能用新增一个算法或一组单元测试代替整体完成。

## 已核对的基线

现有平台支持 CSV/TSV/XLSX、表格分类与回归、按预测时点提取工艺时序特征；已有 scikit-learn、Optuna、AutoGluon，固定评估划分、独立训练任务、停止接续、模型绑定、下载及工作流调用。数据分析此前仅提供概况扫描。工作流建模节点共用宽泛配置，输入输出及表单仍需要按用途整理。

## 本版持续推进的范围

1. 数据操作：明确输入数据形态，提供实际统计与清洗能力，保留原数据及可继续计算的结果。首先覆盖用户点名的异常值处理和 Spearman。
2. 训练预处理：将需要估计参数的清洗、编码、特征筛选放进训练折，保存后在预测时复用。探索性全表分析与模型评估的拟合过程要明确区分。
3. 建模与比较：核对现有引擎的真实能力、可配置范围和限制，在一致的数据划分下比较基线、候选、分组误差与资源消耗。按实际项目失败增加必要能力，不把安装新模型库当成效果提升。
4. 工具与工作流：独立智能体操作和工作流执行使用同一实现，操作可配置、结果可连接、流程可复用；长任务保留停止、接续及环境版本。草稿始终可以在资源就绪前保存。
5. 用户操作：整理宽泛的建模配置，按操作展示参数和输出，明确不支持的数据；基础分析无需用户写代码或 JSON。
6. 工业项目验证：在当前企业项目资料中确定可计算的任务、目标列、划分方式和业务指标，实际跑数据处理、训练、预测及工作流复用。单元测试、构造数据和历史日志不能替代真实项目效果；真实模型调用仍需当次授权。

## 2026-10-16 第一批：数据分析与异常值操作

分支 `codex/ml-capabilities-20261016`，独立工作区；未部署。

`project_modeling(action="analyze", dataset_id, analysis=...)` 与画布 `data_analysis` 使用同一计算实现。旧节点省略 analysis 时继续输出原来的数据概况。

参数例子：

```json
{"operation":"spearman","columns":["temperature","quality"],"missing":"pairwise"}
```

```json
{"operation":"outliers","columns":["temperature"],"method":"bounds","lower":0,"upper":200,"handling":"drop"}
```

- Spearman：逐对有效样本数、相关系数、渐近 p 值、矩阵与 CSV/JSON 文件；支持成对删除、完整行删除、遇缺失值停止。常数列与不足三个样本返回未定义原因，不能把它们写成零相关。
- 异常值：IQR 或指定上下限；只标记、删除所在行、截到边界。只修改明确选择的数值列；缺失值保留，无穷值报错。输出异常位置和原始行号映射。
- 删除与截断产生独立数据集，输出 `dataset_id` 可直接连接下一次分析或训练；原数据不变。运行使用独立版本的建模环境。
- 新操作当前接受单张表格的数值列；独立标签表和工艺时序需要先明确整理，运行时返回具体限制。IQR 在全表估计，不能把这种探索性处理宣称为无泄漏的训练预处理。
- 画布按操作显示参数，并提供中文选项及对应输出字段。列与资源可先留空保存草稿，运行时再检查。
