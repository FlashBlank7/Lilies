# 员工试用：在项目中使用智能体和工作流

更新至 2026-09-28。打开 **http://127.0.0.1:3000/login**；其他电脑使用部署电脑的局域网地址和 3000 端口。登录后进入项目列表。首次注册会显示使用教程，也可随时从顶部「使用教程」重新开始。

## 第一次使用

1. **进入项目。** 在项目列表选择已有项目，或点击「从示例创建」。可以先试会议纪要、周报、费用整理、数据体检等示例；它们会成为你自己的可编辑副本。需要公司的既有项目时，请负责人添加成员。
2. **准备资料。** 打开项目内「项目空间」，在「待处理文件」点击「添加资料」，或「从已有项目选择资料」。示例已经带有自编资料。勾选本次任务使用的文件；文件进入项目本身不会启动分析或训练。
3. **提出任务。** 在「可供调用的工作流」找到合适流程，点击「让智能体调用」；也可以「带着所选资料开始对话」。检查带入的资料和要求，补充你要解决的问题，再发送。若尚无会话，先在「对话」点击「新建会话」。建议问题只准备消息，不自动发送。
4. **查看结果和补充信息。** 在对话查看回答与结果卡，或打开「运行记录」。需要回答时使用问题卡填写；不清楚的业务信息可以明确说不清楚。展开步骤查看输入、输出或错误，通过文件入口预览和下载产物。
5. **修改后再次使用。** 可以追问原因、要求换资料或调整方法；也能从项目空间点击「查看与编辑」，在画布表单中修改并保存。原运行结果保留，新运行采用当前配置。

不必每次指定工作流。可以直接说「请先看看项目里有哪些流程适合这个任务」，智能体会按需发现和调用；简单需求也可直接完成。项目成员共享资料、工作流、模型和已保存结果，各自对话历史独立。

## 可以这样提问

- **不了解数据：**「先检查这份表格，解释缺失、重复和标签分布。告诉我现在能分析什么，还有哪些信息不明确。」
- **分类或数值预测：**「用已有训练流程比较简单基线和少量候选。按批次划分，说明哪些字段在预测时不能使用，保留独立测试结果。」
- **复用已有模型：**「使用项目已绑定的模型预测这份新数据，不重新训练；把需要人工复核的记录单列出来。」
- **日常工作：**「根据这份会议记录整理决定和行动项。没有明确负责人或期限的地方请标出来，不要补写。」

项目里的流程、连接和数据必须适用于任务。业务含义、预测时点或标签不明确时可以补充或纠正；结果应结合真实业务判断。完整机器学习页面操作见[机器学习试用](V06_TRYOUT.md)，示例范围见[示例说明](EXAMPLE_PROJECTS.md)。

## 随时创建工作流

在对话输入区切换「创建工作流」，描述要保留的步骤，并按需选择项目资料和已有流程作参考，再点击「生成新工作流」。生成的是可编辑草稿，不会因此启动训练或其他业务任务；业务模型尚未训练、资源暂未绑定也可以保存。

切回「完成任务」继续解决问题。手工搭建可从项目空间「添加空白流程」开始；没有已有流程时，也可以从「公共工作流市场」点击相应「加入项目」。资源缺项在实际运行时提示。生成和人工修改、撤销及并发编辑的行为见[工作流编辑](V06_WORKFLOW_EDITING.md)。

## 没有模型连接或任务中断

- **智能体不可用：** 查看项目的「智能体来源」及「设置」。官方智能体需要管理员为项目授权；原始模型 API 使用项目连接。普通成员无法配置时联系负责人，不需要填写公司的共享账号凭据。
- **流程中的模型不可用：** 对话所用的官方智能体不等于流程已配置业务模型。LLM、视觉和 Embedding 积木使用各自的原始 API 连接；训练预测还需要对应计算环境或已绑定模型。按具体节点错误补齐资源。
- **输入或业务信息不足：** 根据错误或等待问题卡补充，再继续原任务。不要为通过而删除必要检查。
- **主动停止：** 用当前会话或任务的停止入口，查看已保存状态；需要继续时由你明确操作。继续原运行保留原快照和有效进度，重新运行则创建使用当前配置的新任务。

部署和出口配置由维护者按[官方智能体说明](OFFICIAL_AGENT.md)与[安装说明](V06_INSTALL.md)处理。普通员工无需编辑配置文件。手动编辑、阅读资料等操作不要求先调用模型。

## 给平台提意见

顶部「意见反馈」可以直接提建议；回答、错误或运行结果旁的「反馈给平台」可以关联本次操作。内容片段和截图由你选择是否附带。提交后从「反馈记录」查看回复，也能补充或重新打开问题。反馈操作本身不会调用模型或重跑业务。

管理员通过「使用改进」查看从已有运行记录中整理的线索，可为指定项目开启官方智能体处理。修复结果可查看、比较后用于原流程；已处理线索随后再次失败会有提醒。普通员工无需额外填写使用日志。具体范围见[意见反馈](USER_FEEDBACK.md)和[使用改进](USAGE_IMPROVEMENT.md)。

本阶段验证包含员工模拟、真实计算及有限真实模型任务；不代表每条业务结论均准确。系统文件窗口和实际网络限制见[原型交付说明](RELEASE-v0.6-prototype.md)。客户原始资料、模型和私有报告不随源码发布。
