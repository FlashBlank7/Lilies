# 本机原型试用

入口：**http://127.0.0.1:3000/projects**。启动方式见[README](../README.md)。本原型使用本机 Codex 与 CPU 计算环境，项目内数据、结果和对话会保存。

## 一次完整使用

1. **打开项目。** 可新建项目或导入需求包；导入后不会自行分析。已有工业项目从原项目继续。
2. **上传数据并说明目标。** 在对话下方“导入数据”选择 CSV、TSV 或 XLSX，告诉统筹要预测什么、什么时候预测，以及已知评价要求。上传不会自动训练；仍由你发送消息开始处理。
3. **查看实际分析和模型。** 建模卡片显示当前进展、参照效果和最佳模型。打开“数据”看质量和分布，“特征”看来源，“实验”看候选比较及每个模型的训练笔记。
4. **反馈并继续。** 点击“反馈这个结果”，直接说哪里不合理或希望检查什么。反馈关联原结果，较差模型和历史运行保留。正在执行时可补充，也可停止后继续。
5. **用新文件预测。** 上传同结构无标签数据后说“用已保存模型预测这份文件，不重新训练”。从结果卡片查看业务解释、表格和下载文件；需要检查执行时再展开运行详情。

上传文件不会覆盖已写好的消息。关闭报告、刷新页面后，未发送文字与已选数据版本保留。资料缺失会显示具体问题；补充时沿用原事项，不必重新开始整个项目。

## 试用资料

使用自己获准的数据集及项目模型连接。历史客户资料和报告不随源码发布。

## 遇到中断

- **缺字段或业务信息：** 查看具体错误，补充文件或回答，再针对原结果继续。
- **用户停止或连接中断：** 刷新查看保存状态，从“继续推进”或原任务继续；已完成结果仍可查看。
- **计算环境错误：** 按实际镜像、Docker 或登录错误恢复环境，再回到原项目继续。无需因此更改业务目标。
- **需要迁移或恢复：** 使用[完整备份与恢复](backup-restore.md)，只复制数据库不够。

本次原型面向现有本机环境试用。新电脑安装、生产启动和正式部署仍按[周开发计划](DEVELOPMENT_PLAN.md)推进。
