# 数据工作空间

本功能在项目的「数据工作空间」页提供数据驱动的交互，原有工作流画布、项目任务和运行历史继续可用。左侧是已有表格工具和项目工作流，右侧是文件、数据集、分析结果和模型。拖放只打开配置；点击「确认配置并运行」才创建项目任务。

## 使用路径

1. 上传或展开 CSV、TSV、XLSX，先确认工作表、表头之前及之后跳过的行数。表格展示原值、解析值及缺失/待确认/格式错误状态。
2. 选择字段，添加作用于完整数据的筛选条件，或显式勾选行。可查看分布与散点图；散点超过 1,000 个有效数值对时按固定随机种子抽样并标明。
3. 将工具拖到数据卡片，或将数据卡片标题拖到工具。也可用卡片下方的工具选择框。补齐参数后运行，结果按本次处理展开。
4. 整理字段含义后，同一中间表可分别用于相关分析和训练。训练选择目标、特征、分组、预算和预处理；存在未知含义的值时，明确选择停止或排除并记录原因。
5. 对新表选择「批量预测」及具体历史模型。预测沿用模型固定的语义与预处理，保留全部输入行和无法预测的原因。模型与数据共同列为来源。
6. 结果可继续处理。通过「保存处理链」保存本次处理及必要整理步骤；从左侧调用时选择新数据、读取布局和外部模型。画布可继续编辑。

## 数据与版本规则

- 原值、字段定义、数据状态和源行位置由建模侧同一解析器贯通。服务端分页，浏览器不为首屏下载整表；筛选针对完整数据。
- 文件内容、数据集文件与 mapping、具体模型试验共同确定版本。提交固定版本、选择范围、参数、工作流修订和请求标识；重复提交同一请求复用任务，修改请求须使用新标识。
- 原表字段规则在整理处维护。中间表已固定的字段含义不能直接重解释；应从原始数据重新整理。模型保留训练时规则，后续修改不会改写旧模型。
- 展示名称与分析标记只影响展示或新的分析；改变类别含义、训练样本、特征或训练预处理，需要重新训练和评价。界面保留历史结果，并提示来源或规则不同。
- 预测流程使用显式历史模型输入。保存预测处理链不沿模型来源回溯训练。
- 已完成步骤的产物在失败后保留；整次任务结束才显示完成，失败结果不借用其他运行报告。

## 实现入口

后端 `/api/v1/projects/{project_id}/data-workspace` 提供对象列表、`object`、`preview`、`file`、`catalog`、`operations` 和操作的 `save`。`project_data_workspace` 供项目智能体调用同一服务。Skill 只说明如何配置，未另写一套处理实现。

对象标识为 `file:`、`dataset:`、`model:`、`result:`，内容继续保存在现有项目文件、建模库和工作流运行中。单工具封装为内部工作流，已有工作流通过现有调用节点执行。内部工作流不混入用户流程库。

流程输入可选声明 `resource_kind`、`accepted_formats`、`required_columns` 和 `purpose`；未声明的旧流程保持原运行接口。工作空间无法判断输入用途时会说明需补充声明。保存的表格链将读取布局暴露为输入，以支持换表。

## 当前范围与限制

- 计算范围沿用现有表格机器学习工具；图片预览、DOCX 正文与表格文本、PDF 及隔离 HTML 预览，不新增 OCR 或视觉训练。旧 `.xls` 不在现有建模解析器支持范围内，会显示格式限制。
- 手动勾选的行属于固定数据版本。要保存能换表的处理链，需用字段筛选表达样本范围，避免把旧表行号误用于新表。
- 未声明资源输入的历史流程可继续从原画布运行；要加入拖放组合，需要补充其输入声明。复杂对象参数仍通过已有画布定义，工作空间优先提供表格机器学习表单。
- 当前运行树展示最近 100 次操作，旧任务和工作流运行仍在原历史入口。项目对象可分页加载。
- 本机技术验证不等于真实业务人员可用性研究，也不证明模型达到生产检验收益。

验收结果见 [DATA_WORKSPACE_VALIDATION](DATA_WORKSPACE_VALIDATION.md)。
