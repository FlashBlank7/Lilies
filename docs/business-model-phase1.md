# Phase 1 商业模式：按结果收费的工作流交付服务

> 决策记录（2026-08-21 讨论定稿）。定位 toB；UTOO 站点仅为临时交付基础设施，
> 非品牌方向。定价数字为**起步假设**，以前三单真实成交价校准；条款草案签约前需律师审阅。

## 一、模式一句话

客户给需求和样例数据 → 莉莉丝在我方环境搭建 → 交付使用链接 + 访问码 + 交付包，
客户不接触平台。**卖的是通过独立验收的业务结果，不是软件。**

核心差异化：**验收对赌**。监理机械验收 + 数字锚定测试 + 执行台账 →
商务条款敢写"验收单全绿才付尾款"。传统外包和 LLM 套壳都无法安全承诺这一条，
这是把平台的诚实失败防线直接变成销售武器。

## 二、切口：金蝶星空生态

五个已验证场景中唯一同时满足四条件的：真实 API 已打通（K3Cloud 实测 +
日报盲测全绿）、客户名单可识别（星空用户企业）、痛点高频可量化（对账/日报
每天的人肉劳动）、可复制性强（同 ERP 客户工作流八成相似，第二单边际成本骤降）。

- **渠道**：金蝶实施商 / ISV——手里全是"ERP 上线了但周边自动化没人做"的客户；
- **交付物三件套**：日报、对账、异常预警；
- 珠宝/法律类可接单不主推（每单像新项目，复制曲线差）。

## 三、收费结构（三层）

| 收费项 | 形式 | 起步区间（人民币，待前三单校准） |
| --- | --- | --- |
| 搭建费 | 一次性，按档位 | 简单单 3k–8k · 标准单 1.5w–4w · 深水单 4w–10w |
| 首单开荒费 | 新领域首单 +30–50% | 覆盖新域掉缺陷的排障成本（ERP 首单 6 个缺陷的教训） |
| 托管月费 | 按工作流条数订阅，含额定运行量 | 简单 0.5k–1k/条 · 标准 1k–3k · 深水 3k–8k |
| 运行量阶梯 | 超额 run 计费 | 按 run 计，谷时批量运行成本减半（DeepSeek 峰谷价差） |

**定价锚**：替代人力价值，不是成本加成。例：对账+日报 ≈ 0.3–0.5 个财务专员人月，
月费定其价值的 1/3。**成本地板**只做毛利校验：pricing-baseline.md 三刀后
简单/标准/深水单模型成本 <$0.05 / $0.25–0.35 / $0.55–0.80，
2026-08-16 DeepSeek 峰谷计费后乘 2–4 倍系数——深水单仍 <$4，
模型成本占报价 <1%，毛利结构由人力时间决定（简单单 <1h、深水单 3–6h）。

**付款节奏**：签约 50% 预付 → 交付演示 → **监理验收单全绿付尾款**。
验收标准在签约时用业主样例数据共同冻结（防验收期扯皮，也是出卷机制的商业用法）。

## 四、数据回流授权条款（草案，律师审阅前不得使用）

> 第 X 条 服务改进数据
>
> X.1 为持续改进服务质量，乙方（服务方）可收集并使用甲方工作流的**运行元数据**，
> 包括：任务执行次数与耗时、步骤结构统计、错误类型与频次、资源消耗统计。
>
> X.2 运行元数据**不包含**甲方的业务数据内容。甲方输入的业务数据（单据、报表、
> 客户信息等）及工作流输出结果，乙方仅为向甲方提供服务之目的处理，
> 不用于服务改进分析，不向任何第三方披露。
>
> X.3 乙方对收集的运行元数据采取脱敏处理，确保无法据此识别甲方身份或
> 还原甲方业务内容；脱敏后的统计数据可用于乙方产品改进与质量分析。
>
> X.4 甲方可书面要求乙方停止收集运行元数据；该要求不影响已依约提供的服务，
> 但乙方可相应调整服务承诺范围（因缺乏运行数据支撑的主动性维护除外）。
>
> X.5 本条项下数据的保存期限为服务终止后 [12] 个月，期满删除。

技术实现即 field_report 脱敏导出（默认不含需求原文与业务参数），条款与实现一致。

## 五、UTOO 的角色与客户可见面清理

UTOO = 临时交付基础设施（机器 + 反代），**不是品牌**。首个付费客户落地前完成：

1. 使用页（/use 访问码页）与交付包去除 UTOO 视觉元素，换独立 B 端品牌；
2. 客户链接走独立域名（反代加一个域即可，不动部署结构）；
3. 交付包 README 的署名与联系方式统一为新品牌。

## 六、阶段推进触发条件（可度量）

- **Phase 1 → 2（受控自助）**：累计 10–20 单，莉莉丝独立完成度 ≥ 90%
  （人工介入次数由 field_report 计量），模板库覆盖新需求 70%+；
- **Phase 2 → 3（私有化）**：小模型 builder 盲测打平大模型基线——
  本地小模型集群 + 执法 harness = 客户环境零外部 API 依赖、token 边际成本趋零。
  研究线（small-model-builder-design.md）与商业线在此汇合。

## 七、不做清单（与做什么同等重要）

- 不卖平台席位 / SaaS 订阅（自主能力未过"无人在环"门槛前不开放自助）；
- 不做私有化部署（小模型路线跑通前，等于把无兜底的平台扔进客户机房）;
- 不建多租户 / 计费 / 权限体系（等付费拉力出现再建，避免为不存在的规模付税）。
