# v0.2.21 Platform Harness Secret References

## 1. Stage Goal

Complete the Platform Harness secret reference injection slice carried from `v0.2.20`.

This stage provides a safe path for legitimate secret use without weakening inline secret-field blocking:

- Platform Harness stores per-owner secrets in the local metadata store;
- API create/list/delete returns only redacted metadata and `secret_ref`;
- workflow configs can use `{"$secret": "name"}` or `{"$secret": "owner/name", "prefix": "Bearer "}`;
- runtime enforces secret policy before injection and injects only at execution boundary;
- missing references fail clearly;
- existing plaintext secret fields remain blocked;
- focused regression tests prove the boundary.
