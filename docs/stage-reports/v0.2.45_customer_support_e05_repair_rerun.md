## 5. Experiment Conclusion

v0.2.44 repair is partially validated.

The best signal is `shallow`: it now successfully expands the customer-support template and reaches `ready` without provider timeout. This directly addresses the v0.2.43 shallow failure mode.

The `deep` arm remains unresolved. It can now preserve a benchmark-clean structure, but it still exceeds the 600 second Builder deadline and ends in `needs_attention`. Therefore deep reuse depth is not yet an industrially reliable default path.

Original E05 remains open. The evidence is still limited to one customer-support task family, and the project still needs more task-family/template evidence before claiming general Template reuse-depth quality gains.
