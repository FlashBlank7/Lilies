- DOCX: `docs/experiment-status/reports/2026-07-09_2013_E02_readable_testframe_reviewer_proxy.docx`

| Metric | raw_legacy_json | readable_testframe |
| --- | --- | --- |
| Serialized chars | `2433` | `5524` |
| Estimated total JSON paths | `18` | `10` |
| Explicit category/title/failure target/hints | mostly absent | present |
| Paid reviewer proxy score | `0.375` | `1.0` |
| Paid reviewer duration seconds | `3.164` | `3.533` |
| Prompt chars | `2804` | `5898` |

Conclusion:

- Readable TestFrame/report improved failure localization and repair-action extraction in the paid reviewer proxy.
- Deterministic metrics also favor readable report for semantic field discovery despite larger serialized size.
- The result supports using readable report as the default reviewer-facing layer and raw JSON as a debug detail layer.
- The result does not prove real human review-time reduction.
