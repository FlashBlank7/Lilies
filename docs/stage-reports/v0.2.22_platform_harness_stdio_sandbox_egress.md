# v0.2.22 Platform Harness Stdio MCP Egress Guard

## 1. Stage Goal

Complete the immediate stdio MCP egress bypass guard carried from `v0.2.21`.

This stage does not implement a full interactive sandboxed stdio MCP runner. It closes the current unsafe gap: stdio MCP servers do not declare hostnames, so restricted network policies cannot apply allowlist/none semantics. Under restricted platform or agent network policies, stdio MCP is now blocked before process start.
