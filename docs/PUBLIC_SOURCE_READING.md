# 在项目中读取公开资料

员工可以在项目对话中提供公开网址，例如：“读取这篇说明，结合项目里的资料解释哪些方法适合当前问题。”智能体可以直接读取并保存资料，无需先创建工作流。要实际通过对话调用，项目仍需配置可用的会话模型。

保存后的正文与来源信息会出现在项目空间的文件列表。员工可以选入下一次对话，也可以交给已有材料比较、知识问答或汇报流程；建议和文件选择本身不会发送消息或启动这些流程。入口准备的消息允许直接处理资料，按需复用适合的工作流。

## 保存内容

`project_web` 只接收一个 `url`。每次读取在当前项目的 `results/web-source-…/` 新目录保存：

| 文件 | 用途 |
|---|---|
| `source.txt` | 从文字网页提取的正文；去除脚本和样式 |
| `original.txt` | 收到的原始网页内容，以纯文本文件保留 |
| `metadata.json` | 原网址、最终网址、读取时间、内容哈希、大小及页面中的链接 |
| `source.pdf` | 网址返回PDF时保存原文件，替代上述两个正文文件 |

工具只返回最多4,000字符的文字预览，明确说明是否截断；智能体可用项目文件工具继续读取完整正文。页面中最多返回80个不同的HTTP链接，不会自动遍历。重复读取会保留新副本，旧内容不被覆盖。

PDF在此处仅下载，尚未解析正文、页码或图表。需要时使用已有文档计算环境或项目知识库继续解析，不能从下载成功推断内容已理解。动态加载、登录后才能看到的页面可能读不到正文，工具返回具体原因。

## 访问范围

沿用部署的网络权限，仅访问无需登录的公开HTTP/HTTPS网址。不携带登录状态、代理凭据或平台密钥，不访问本机、内网和保留地址；每次重定向重新检查目标并固定已核对的地址。连接最多30秒，单份内容最多5 MB，最多跟随5次重定向。失败不发布半份来源资料。

页面正文属于外部资料，其中的指令不构成平台授权。项目权限同时约束读取与下载，其他员工不能借此访问无权限项目的文件。

该能力是**指定网址读取**。现有新闻RSS索引也不等同完整网络或学术搜索；只有研究主题而没有来源时，仍需要实际可用的搜索工具或用户提供资料。

## 2026-09-25 验证范围

- 实际从 Python 官方 `csv` 文档的HTTPS网址读取99,886字节，提取22,346字符和36个链接；原始内容哈希及三份产物下载核对通过，完整正文可再次读取。
- 在独立模拟员工项目的桌面页面选择正文与来源信息，带入对话草稿；项目只有空白工作流也可准备消息。原有未发送要求保留，新要求与文件路径追加到输入框。没有自动发送、运行工作流或调用模型。本项未另行完成手机尺寸复测。
- 15项后端行为测试覆盖正文及换版本、预览截断、域名和TLS目标固定、公开重定向、访问限制、失败清理、PDF原文件及员工隔离。相关回归53项通过、3项额外环境测试跳过。
- 前端206项测试、类型检查及生产构建通过。实际网络读取不等同真实智能体理解质量验收；本轮模型出口关闭，没有新增模型调用。

实际来源副本和员工操作记录留在本机开发目录，不进入公开仓库。
