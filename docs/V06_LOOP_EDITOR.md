# v0.6 循环内部人工编辑

选中“迭代”或“循环”积木，点击“进入循环内部编辑”，也可以双击积木进入。顶部显示当前层级，“返回上层”逐层返回。沿用运行时现有的两层循环嵌套支持。

内部画布与外部画布使用相同的节点表单、积木库、连线、删除和布局操作。内部保存转换为一次带草稿修订号的容器更新；不会因为内外层节点同名而修改错误的节点。操作提交后即使切换层级，排队中的修改仍指向提交时的内部图。

循环输出积木使用下拉选择。字段引用器显示当前内部图的上游节点、循环传入变量、当前元素与序号，循环积木还显示状态、上一轮输出和反馈字段。状态更新与退出判断引用内部结果；初始输入仍引用外层上游。条件节点的连线可以直接选择分支，并支持删除当前连线。高级 JSON 编辑仍保留。

AI 修改跟随当前画布层级；选择内部节点后，提交同时携带内部路径和节点标识，保留其他部分。用户仍可手动选择修改整个工作流。未保存的配置需要先保存再切换层级，以免输入丢失。
