# 实测反馈修正与分段建议

2026-09-25。公共工作流市场和同名示例提供独立可编辑副本，附项目Skill。员工可以直接运行表单，也可以让项目智能体发现并调用。流程使用代码积木，不训练、不调用大模型或现场接口。

## 如何使用

1. 准备同一对象的一维等间距风险曲线，默认字段为`position,score`。坐标是每格中心，严格递增、无重复；风险分数0至1，越大表示越有风险。填写实际网格宽度与单位，不自动补缺口。
2. 观测表默认字段`observation_id,position,high_risk`；高风险填1、低风险填0。未知项先复核，不能猜测。坐标必须处于曲线覆盖区间，若有`unit`列必须与表单一致。两张表的坐标和分数/结论列名可配置；CSV、TSV与Excel均可，多工作表需选择。
3. 根据任务资料填写影响宽度、修正力度、分数裁剪上下限，以及保留、排除与状态切换的代价。同坐标的不同观测按文件行顺序使用；重复观测ID报错。
4. 查看前后分段及说明，下载逐点分数/动作、分段、实际观测顺序、配置与输入快照。修改参数或换观测另开运行，旧结果保留。再次计算仍选择原始曲线和完整观测表，避免重复应用同一次反馈。

观测表留空时仅计算原分段，原分数完全保留。一次最多10000格、200条观测，文件10 MB；超出明确报错，不静默截断。

## 方法与限制

观测按顺序应用，高斯权重为`exp(-距离²/(2×影响宽度²))×力度`，将当前分数拉向观测的0或1，全部更新后按声明上下限裁剪。这是顺序相关的经验修正，**不是贝叶斯推断或校准概率**。

自编示例中心分数0.1，力度0.8；先高风险得到0.82，再低风险得到0.164。反转两条观测得到0.804。说明中用这一差异提醒员工核对观测顺序，而非自动选择看上去更好的结果。

分段采用两个状态：每格保留代价为格宽×保留风险单位代价×分数，排除代价为格宽×排除单位代价；相邻状态变化再加切换代价。动态规划最小化本次离散目标，同值按保留优先的稳定遍历处理。报告同时将旧分段放到新分数上计价，两个方案以同一口径比较，不把分数改变等同收益增长。

曲线覆盖首尾中心外各半格，内部状态边界与端部切割不同。流程不包含最短段长、切缝、设备、总需求、已切除区域或不可逆现场约束，输出为分析建议。单独比较预测误差使用既有[反馈对照](PREDICTION_FEEDBACK_WORKFLOW.md)，生产模型效果需另行评价。

## 来源与验证

- 提取自原反馈工程的邻域修正和两状态分段方法；原代码以“贝叶斯后验”命名，但实现没有该统计保证，公共流程按实际算法解释。客户专有变量、固定尺寸与代价不作为通用默认；只有自编示例预填教学数值。
- 原未修改模块在禁网、只读Docker执行8组构造输入；平台实际执行相同输入。53个网格分数最大差小于10⁻¹²，前后分段、内部边界及长度一致，48项文件可读取。覆盖相反观测顺序、无观测、裁剪、单格及大切换代价。不是客户生产数据效果验收。
- 独立穷举核对短网格全部0/1决策的最小代价，测试边界、重复与未知观测、缺口、精度、换输入、快照及修复。工具接口发现、读取和调用原工作流成功，不用真实模型替代算法检查。
