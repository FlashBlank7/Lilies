# Lilies 新用户使用教程

新注册账号进入平台后自动开始页面引导。顶部“使用教程”点击即开始，不再经过欢迎卡。旧账号不会无故自动弹出；进行中的教程刷新后接续。

1. **进入项目。** 公司项目由负责人在“设置 → 项目成员”添加你的用户名；也可以自行创建项目。同项目共享资料、工作流、模型与结果，各自对话独立。
2. **准备资料。** 在“项目空间”选择已有文件或添加资料。勾选本次文件，再带着资料开始对话。
3. **找到工作流。** 查看流程的用途和输入要求。没有合适流程时，可加入官方流程的独立可编辑副本；加入不会启动业务。
4. **通过对话调用。** 点击“让智能体调用”，没有会话时先新建会话。检查输入框内的流程、资料和业务要求，再点击发送。已有草稿会保留。没有模型连接时，负责人可配置，协作者联系负责人；仍可继续阅读教程。
5. **查看运行与结果。** 在对话结果卡或“运行记录”查看进度、停止、错误与结果。点击结果文件先预览，再通过“下载原文件”下载。
6. **了解后续用法。** 对话里的“完成任务”用于处理问题，“创建工作流”用于生成可复用流程。工作流可在训练未完成、资源未绑定时保存，也可以通过画布表单编辑。

“下一步”只推进讲解。操作清单根据真实操作记录，不会因为翻页而勾选，也不要求实际运行或训练才能结束教程。教程不会自动发送消息、生成工作流或调用模型。

引导将当前操作区域点亮，其余背景变暗并阻挡点击；跳转页面、打开弹窗和输入时继续引导。完成进入项目、选择资料和发送请求后进入相应下一步；查看流程或结果后可点击“下一步”。

点击“跳过引导”或按 Escape 会显示温和提醒：跳过后寻找入口可能不太顺手，可以继续引导或确认“暂时跳过”。确认后恢复正常页面，刷新不再自动展开；之后点击顶部“使用教程”可重新开始。结束或重开教程不修改项目和草稿。进度按账号保存在服务端。

现有账号不会自动弹出教程。项目不可访问时需重新选择项目；教程进度暂时无法读取或保存时，可以重试，正常业务操作不受影响。


## 官方智能体与内部共享

管理员从全局导航打开“官方智能体”，配置订阅服务、额度保留和并发；再在项目对话的“智能体来源”授权并选择它。员工使用自己的会话，无需填写服务凭据。排队、停止、生成任务刷新接续、结果保存方法、项目间分享与统计说明见 [官方智能体使用说明](OFFICIAL_AGENT.md)。

## 从示例开始

在项目列表点击「从示例创建」，可从 25 个日常办公、数据处理、机器学习、知识问答及流程搭建示例中选择。每次创建都得到自己的可编辑项目，包含自编或合成资料、流程、默认参数和使用说明。

项目顶部「准备这条消息」只把建议问题追加到草稿，检查后由你发送；「操作步骤、工作流与修改练习」提供资料、画布和运行表单入口。缺少连接或环境时先按准备条件配置；创建示例本身不调用模型、不训练。首次注册的强引导也可从示例入口开始。

完整清单、使用方法和已验证范围见 [示例项目说明](EXAMPLE_PROJECTS.md)。


新手拿到表格后，可从「数据入门：从看懂资料到选择方法」示例开始，或加入「数据摸底与分析建议」。等待补充时直接在对话卡片或运行详情回答，无需填写 JSON；「不清楚」也可继续得到已有结论。见 [经验工作流使用说明](DATA_GUIDANCE.md)。
