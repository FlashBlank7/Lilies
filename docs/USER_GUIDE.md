# Lilies 新用户使用教程

新注册账号第一次进入平台会显示欢迎卡。点击“开始引导”，跟随页面上的“去操作”打开真实入口。已有账号可以从顶部“使用教程”打开。

1. **进入项目。** 公司项目由负责人在“设置 → 项目成员”添加你的用户名；也可以自行创建项目。同项目共享资料、工作流、模型与结果，各自对话独立。
2. **准备资料。** 在“项目空间”选择已有文件或添加资料。勾选本次文件，再带着资料开始对话。
3. **找到工作流。** 查看流程的用途和输入要求。没有合适流程时，可加入官方流程的独立可编辑副本；加入不会启动业务。
4. **通过对话调用。** 点击“让智能体调用”，没有会话时先新建会话。检查输入框内的流程、资料和业务要求，再点击发送。已有草稿会保留。没有模型连接时，负责人可配置，协作者联系负责人；仍可继续阅读教程。
5. **查看运行与结果。** 在对话结果卡或“运行记录”查看进度、停止、错误与结果。点击结果文件先预览，再通过“下载原文件”下载。
6. **了解后续用法。** 对话里的“完成任务”用于处理问题，“创建工作流”用于生成可复用流程。工作流可在训练未完成、资源未绑定时保存，也可以通过画布表单编辑。

“下一步”只推进讲解。操作清单根据真实操作记录，不会因为翻页而勾选，也不要求实际运行或训练才能结束教程。教程不会自动发送消息、生成工作流或调用模型。

“收起”暂时让出页面；输入框获得焦点时也会自动收起。“稍后继续”停止自动展示，下次从顶部“使用教程”继续。“从头查看”会重置教程进度，不修改任何项目或结果。进度按账号保存在服务端，换设备登录后可接续。

现有账号不会自动弹出教程。项目不可访问时需重新选择项目；教程进度暂时无法读取或保存时，可以重试，正常业务操作不受影响。


## 官方智能体与内部共享

管理员从全局导航打开“官方智能体”，配置订阅服务、额度保留和并发；再在项目对话的“智能体来源”授权并选择它。员工使用自己的会话，无需填写服务凭据。排队、停止、生成任务刷新接续、结果保存方法、项目间分享与统计说明见 [官方智能体使用说明](OFFICIAL_AGENT.md)。
