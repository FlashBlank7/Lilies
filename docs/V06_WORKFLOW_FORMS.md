# 工作流表单配置

画布配置面板默认使用表单，完整 JSON 仍放在高级入口。常用输入输出、变量和请求字段可逐行添加、命名、选择类型或引用上游。文本编号保留前导零；数字和布尔值通过类型控件明确选择。字段重名不会覆盖已有字段。

引用选择器只列出沿连线可达的上游节点，排除自己、下游及其他分支。可选择节点已声明的输出字段，以及 LLM 结构化输出、输入字段和变量赋值中的具体字段。复杂路径保留手动填写入口；旧的未连接引用会显示提示，不自动删除或替换。

模型资源和数据集从项目中选择；未就绪可稍后绑定。LLM 根据当前选择的主模型/视觉用途读取对应连接。图片可直接选择项目 PNG/JPEG 文件或引用上游图片列表，不必编写图片数组。条件分支可添加条件、选择比较方式、填写有类型的比较值，并组合为全部满足或任意满足。

页面用积木 schema 的缺省值显示未填写的可选配置；不会因旧草稿省略系统指令等默认参数而错误要求用户重填。已保存的明确值和未知字段保留。分支标识修改后仍需同步调整对应连线。后续已补齐 [循环内部人工画布](V06_LOOP_EDITOR.md) 和 [项目知识库及语义检索](V06_KNOWLEDGE.md)。
