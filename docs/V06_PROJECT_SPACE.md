# 项目空间与对话创建工作流

现有项目就是工作环境。进入项目的“项目空间”，把要解决的问题所需的文件和可调用的工作流放在一起；员工从项目对话提出任务，智能体按需读取资料、查看流程输入并调用已有流程。

## 使用方法

1. **准备空间。** 在“项目空间”添加文件，或从有访问权限的其他项目复制资料。现有项目业务工作流自动列入空间；可以添加空白流程，也可以导入工作流 JSON 定义。导入会创建当前项目的独立副本，不复制凭据。引用子工作流时，子流程必须已加入本项目。
2. **通过对话使用。** 勾选本次资料，点击“让智能体调用”或“带着所选资料开始对话”。页面带入文件路径和流程标识，用户补充要求并发送。智能体也会在普通对话中看到空间的文件和工作流摘要，不要求每次指定流程。
3. **创建新工作流。** 在同一个对话输入区切换“创建工作流”，描述需求，可勾选已有流程和文件作为参考。点击“生成新工作流”后，新草稿保存在当前项目；参考流程保持原样，生成不会启动业务任务。
4. **编辑与调用。** 对话中的结果卡可查看步骤、打开画布、继续修改或切回任务模式使用。撤销入口恢复本次生成前的节点和连线；新建流程撤销后保留空白成员。修改或撤销遇到其他人的新修订时返回冲突，不覆盖已有编辑。

创建不要求业务模型已经训练好或数据已经绑定；调用生成模型本身仍需要配置有效连接。运行时检查业务资源。生成模式与任务模式共用输入区，切换时保留未发送内容；创建失败保留需求和所选参考。

## 共享与上下文

- 同项目成员共享工作流、文件和已保存业务结果，各人的对话历史独立。创建结果记录在发起人的会话中，生成的工作流对有项目访问权的成员可见。
- 普通任务默认读取全部业务工作流的摘要，即使正在处理某个事项，也能发现空间中其他可复用流程；文件默认只提供前 40 项的路径和大小，更多资料通过工具按目录查找。
- 直接生成最多引用 8 条流程、20 个文件；提供当前会话最近 8 条用户或助手消息，每条最多 2000 字符。文件只提供路径和大小，不自动解析全部正文。需要依据内容生成时，可先在任务模式分析资料，再带着结论切换创建模式。
- 创建流程只调用一次生成模型，没有自动重试、计划审批或自测门槛。项目禁止的积木仍不能导入、保存或执行。

## 2026-09-21 验证

实际本机服务完成测试账号注册、项目创建、页面添加空白流程、查看共享文件与流程、勾选文件进入首次对话、保留创建模式和草稿、选择参考流程及文件。缺少生成连接时页面明确报错，需求和选择保留。页面回到空间可以进入流程画布和运行记录。

小型 CSV 与文件路径回显流程由开发接口准备，实际调用项目智能体工具启动平台运行，成功返回所选文件路径；这验证资源可用和调用路径，不代表机器学习业务效果，也不冒充真实模型自主选择流程。

受影响后端测试首轮 74 通过、3 跳过；追加空间发现用例后本文件对应的 5 项通过（与首轮重叠）。测试包含真实文件保存/读取、工作流运行、跨项目拒绝、私有会话隔离、参考流程不被修改、未绑定模型草稿可保存、生成不启动任务。生成模型使用测试替身，所有自动测试关闭模型出口。本轮不追加外部模型费用；真实模型对新组合需求的生成质量未复验。原生系统文件选择窗口沿用既有未实测边界。
