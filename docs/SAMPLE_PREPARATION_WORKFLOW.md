# 样本清洗与逐行特征准备

2026-09-25。从质量数据工程提炼的通用流程：员工能检查每条记录去了哪里、标签如何处理、特征怎么算，并用同一方法处理下一份数据。使用现有代码积木及计算服务，不新增训练运行时或统一执行阶段。

在项目空间「公共工作流市场」加入同名流程，或从示例创建「样本清洗与逐行特征准备」。独立副本包含可编辑节点和项目Skill；示例使用自编资料，不含客户字段或阈值。建议问题只准备消息，用户发送后智能体按任务发现和调用。

## 怎样使用

1. 选择CSV、TSV或XLSX；多工作表需要指定名称。每行一个样本，第一行是唯一字段名。复合表头、编号解析或复杂工艺公式仍由代码处理。
2. 按实际需要填写必填列、数值列及样本标识列，每行一列。不知道标签含义时可先不设置标签，调用数据摸底流程了解；这不是训练前的强制步骤。
3. 如需整理有标签样本，指定标签列；只有明确知道对应关系时填写标签行表。原值精确匹配，不把1.9变成1，不把未知类别猜成合格或不合格。不填对应关系则保留非空原标签。
4. 指定输出中排除的字段，例如实际预测时尚不可知的事后检测结果。标签和这些字段不能用于新特征。普通记录中的标识仍需由后续特征选择排除或声明为元数据。
5. 按需在特征行表添加两列的和、差、绝对差、乘积、比值，或固定数的缩放、偏移。后行可引用前行的新列；不覆盖原字段。复杂方法可以直接编辑代码节点，首版不把全部特征方法做成独立积木。
6. 运行后查看数量、逐条原因、标签分布、公式和数据预览，下载完整处理表、排除表、字段问题及方法。结果不会自动启动训练或预测。

## 处理口径

| 情况 | 结果 |
| --- | --- |
| 必填列缺失、标签缺失、映射表未列出的标签、全空记录 | 排除并保留原记录及具体原因 |
| 可选数值非法、公式所需值缺失、分母为0 | 默认保留该记录、相应输出为空并说明；可明确选择排除此类记录 |
| 原单元格完全相同的额外记录 | 默认全部保留并说明；可选择仅保留第一次 |
| 同一标识但内容不同 | 不擅自合并或选第一条，保留双方并显示相关记录号，核对实际样本单位 |
| 数据少或稀有标签 | 显示数量，不据此保证类别可靠性，也不自动合并类别 |
| 需要均值填补、标准化、编码或特征筛选 | 继续使用现有训练折内预处理，本流程不对整表拟合 |
| 全部记录被排除 | 交付排除原因及空的结果表，说明不能据此进行后续建模 |

相同标识不一定就是错误重复，例如不同时间或工序的合法观测。是否应按设备、批次或时间划分，需要结合预测时点确定。一个记录可以有多个排除原因，不能把各原因数量相加当成排除总数。

数值限定为有限值、最多40位有效数字、非零数量级在1e-40至1e40；逐行计算使用40位十进制精度，分母0不加极小数掩盖。首版单文件10 MB、2万条记录、200原始列、50特征和200标签映射。Excel读取保存的值，不执行单元格公式。记录号按表头为1的数据记录顺序计数，含换行的CSV单元格不等于物理文本行号。

## 换资料与连接后续任务

输出 `source_path` 指向处理后的CSV，可直接作为现有分析、训练或预测流程的输入。去向、排除原因等辅助字段保存在独立表中，避免被自动当作模型特征。`row-status.csv` 对应输入和输出记录号，`excluded.csv`保留被排除的原值，`issues.csv`保留转换或失败明细。

`method.json`保存方法参数、输入输出字段、方法版本及实际处理代码内容标识。换资料并沿用方法时选择此文件；其他方法参数不生效，报告明确说明。新数据模式不要求标签存在，并从输出移除标签，其余处理一致。

若处理节点代码已经改变，沿用旧方法会指出不一致。可以使用原工作流版本；确需改方法时清空沿用文件，明确修改表单或代码后新建运行。修改报告节点不改变处理节点的代码标识。新运行和旧文件独立保存，不覆盖历史。

模型预测服务不会自动调用这个准备流程。训练使用处理后的表时，新数据也应先经过训练时保存的方法，再交给模型；训练服务自身仍保存折内预处理、模型和运行环境。本流程不把输出表存在等同于数据语义已经正确或模型有效。

## 方法来源和实际验证

- 核对原质量工程的表头解析、标签处理、数值转换、几何差值、乘积和比值，以及既有训练折内处理。保留通用逐行计算与可解释处置；原标签含义、编号正则和工艺假设留在私有版本。
- 在禁网Docker中执行原纯函数，构造边界记录确认：1.9和2.5会经过整数转换落入已知类别；全表标准化在追加一个值后会改变之前记录。通用流程不继承这两种做法；原客户代码没有被修改。
- 对现有382条已解析公司记录，平台实际执行六项逐行计算，2,292个结果与原函数在1e-10数值容差内一致，缺值对应一致；另用其中12条去标签资料验证同方法处理后一致。这里是算术与调用验证，未新增训练，不是外部数据模型效果验收。
- 自编示例覆盖空行、重复、标签缺失、未映射、同标识内容冲突、非法数值和零分母。初次10条保留5条；选择排除转换问题后保留3条。换新数据模式可处理2条无标签记录。
- 自动测试覆盖保存方法、更换输入、标签精确匹配、全部公式、顺序依赖、无整表拟合、缺字段、Excel工作表、历史快照、代码变化及现有分析流程衔接；模型出口关闭。
- 独立模拟员工从页面创建、打开画布、运行、修改策略、修复用途与标签缺项，再选择原方法处理新资料；运行完成后新方法直接进入文件下拉，表单不重置。四次运行包含三次成功、一次明确失败，旧报告及21个产物仍可下载。桌面与390×844下检查报告、表格内部滚动及实际CSV/Markdown下载。
- 本阶段受影响后端129项通过、10项需额外计算配置而跳过；前端192项、类型检查及生产构建通过。没有新增付费模型调用。
