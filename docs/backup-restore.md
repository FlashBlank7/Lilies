# 本机项目备份与恢复

备份覆盖完整 `data/` 和 `workspaces/`：数据库、上传数据、模型、训练笔记、Optuna 记录、需求资料、项目脚本、运行产物和本机 Codex 会话。它不包含平台源码、Python/Node 安装环境或 Docker 镜像；恢复时使用对应平台版本，保留研究记录绑定的镜像。

## 备份

先停止平台 API 及其计算任务，再在仓库根目录执行：

```sh
./scripts/backup.sh
```

默认读取 `data/`、`workspaces/`，保存到 `backups/日期-标识/`，并保存当前 `.env`。自定义位置时：

```sh
./scripts/backup.sh /path/to/data /path/to/backups /path/to/workspaces
```

也可明确指定配置：

```sh
.venv/bin/python -m agent_platform.backup create \
  --data /path/to/data --workspaces /path/to/workspaces \
  --output /path/to/backups --config /path/to/config.env
```

API 与备份共用目录锁；新版 API 运行期间会明确拒绝备份。首次升级前的旧 API 没有此锁，仍须先停止。单独运行的旧脚本或外部工作进程也必须先退出。

备份在临时目录完成复制和数据库检查后才显示为完成；中途失败不会留下可误用的完成目录。APFS 同卷优先使用独立文件克隆，其他文件系统正常复制，不使用硬链接。克隆后的源文件、备份和恢复副本可以独立修改。

外层备份目录权限为 `700`，配置为 `600`；备份包含凭据和企业资料，`backups/` 已加入 Git 忽略。同盘克隆适合本机恢复验证；要应对磁盘故障，仍需将完整备份目录复制到独立存储，并检查其访问权限。符号链接按链接保存，不跟随它们复制本机其他文件。

## 恢复

恢复只写入尚不存在的新目录，不覆盖现有项目：

```sh
.venv/bin/python -m agent_platform.backup restore \
  /path/to/backups/日期-标识 /path/to/restored-lilies
```

恢复后包含 `data/`、`workspaces/`、恢复来源说明及已保存的 `.env`。配置中的数据和工作区路径指向新目录，平台模型出口保持关闭。平台保存的运行工作区路径随目录更新；客户代码、固定草稿、输入、输出与历史评价不做全文替换。用户脚本自行写死的绝对路径、外部文件、连接器及外部数据库需另行处理。

在对应平台版本中使用恢复的配置启动。切换正式使用前停止旧实例，避免两个实例同时执行定时或外部业务；临时校验副本也不要启动无关定时任务及连接器。恢复本身不会启动任何任务。

1. 查看项目会话、进展、原任务、最佳模型及训练笔记。
2. 使用已有模型完成一次预测，检查结果文件。
3. 对等待或中断的事项点击继续；不要重新提交已完成训练。
4. 确认后再以恢复目录作为正式数据位置，原目录保留用于回退。

Codex 仍使用当前电脑的本机登录。平台会重连本项目保存的 thread，并优先读取恢复目录中的会话文件；不会通过新建空白会话掩盖原记录缺失。换电脑时需先安装兼容 CLI 并登录；个人主目录中的登录凭据没有随符号链接内容打包。

当前 CLI 的分页会话还在本地索引保存绝对路径。恢复工具仅在离线副本中迁移 `threads.rollout_path` 和 `threads.cwd`，先检查实际表结构；结构不兼容时恢复失败并保留原备份。该迁移不是运行中共享 Codex 数据库的接口。

文件数量、大小和 SQLite 完整性会在恢复时检查；这些检查不能替代独立存储上的长期校验，也不表示每个历史工业模型都经过重新验证。

## 开发验证

`tests/test_backup.py` 覆盖完整文件复制、独立修改、中文路径、只读需求资料、符号链接、运行中拒绝备份、失败清理、拒绝覆盖、缺失模型、数据库损坏，以及真实协作运行器恢复等待任务且不重复占用资源。`tests/test_codex_app_server.py` 覆盖恢复目录中的原 thread 与本机登录重连协议。

Codex 的恢复调用及实验字段以[官方 App Server 文档](https://learn.chatgpt.com/docs/app-server)及当前已安装 CLI 生成的协议为准；当前使用 `thread/resume` 的 `path` 和 `excludeTurns`，升级时保留协议测试。


本机隔离恢复已有试用；客户数据及详细运行记录保留本地。异机安装及恢复需在目标环境验证。
